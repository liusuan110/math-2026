# 06_AI_Model_Figures

本目录面向有 AI、信号处理、电赛经验的建模队伍，提供适合论文使用的结构图模板。

## 模板

- `neural_network_structure.drawio`：通用神经网络结构图。
- `GNN_structure.drawio`：图神经网络建模流程。
- `signal_processing_flow.drawio`：信号处理与分类流程。

## 使用建议

- 若模型只是普通机器学习，不建议强行画深度学习结构图。
- 若使用 LSTM、GNN、CNN，应在正文中解释输入、特征、输出含义。
- 图中节点不宜过多，重点突出数据流和模型结构。
