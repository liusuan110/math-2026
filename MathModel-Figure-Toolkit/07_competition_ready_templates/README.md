# 07_competition_ready_templates

这是比赛现场优先使用的一层“可直接开画”模板。它和外部工具目录的关系是：

- `external-tools/figure-tools/`：外部优秀项目源码，用来查资料、学写法、复制成熟技巧。
- `MathModel-Figure-Toolkit/07_competition_ready_templates/`：我们自己的赛时模板，用来快速生成论文图。

## 目录

| 目录 | 用途 |
|---|---|
| `python_static_plots/` | Python 论文级静态图模板：预测对比、敏感性、优化收敛、热力图等 |
| `matlab_export_templates/` | MATLAB 出图统一风格和 `export_fig` 导出模板 |
| `physics_3d_templates/` | 物理 / 工程类题目的三维机制图、轨迹图、覆盖/遮挡图模板 |
| `figure_checklist.md` | 比赛提交前的出图检查清单 |

## 赛时推荐顺序

1. 先用模型代码输出结构化结果：`csv / xlsx / json / mat`。
2. 再用本目录模板画论文图，不要把核心建模逻辑和画图混在一起。
3. 每张图至少保存 `png` 和 `pdf/svg`。
4. 论文中优先插入矢量图；交流和临时检查用 `png`。
5. 最后用 `figure_checklist.md` 逐项检查。

## 偏物理 / 工程题的最低图形配置

如果选择类似烟幕、定日镜、碳化硅、多波束、板凳龙这类题，论文中至少应该有：

1. 场景几何图：坐标系、对象、关键距离、角度。
2. 机制判据图：遮蔽、反射、厚度、覆盖、碰撞或采样判据。
3. 时间/空间演化图：轨迹、状态量随时间或空间变化。
4. 优化过程图：收敛曲线或搜索结果分布。
5. 参数敏感性图：关键参数扰动下结论是否稳定。
6. 方案对比图：基础方案、优化方案、鲁棒方案。
