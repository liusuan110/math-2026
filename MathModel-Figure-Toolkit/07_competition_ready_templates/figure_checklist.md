# 数学建模赛时出图检查清单

## 一、图是否真的服务论文结论

- [ ] 每张图能对应正文中的一句明确结论。
- [ ] 图注说明了变量、方法和主要发现。
- [ ] 图中没有“看起来很炫但正文不用”的装饰信息。
- [ ] 所有缩写、符号、单位都能在正文或图注中找到解释。

## 二、基本视觉规范

- [ ] 坐标轴有名称和单位。
- [ ] 字号插入论文后仍然可读。
- [ ] 线宽、字体、配色在全文基本统一。
- [ ] 没有直接使用默认彩虹色。
- [ ] 热力图有色条，色条含义和单位清楚。
- [ ] 图例没有遮挡数据主体。
- [ ] 中文、希腊字母、负号没有乱码或缺字。

## 三、物理 / 工程类题专用检查

- [ ] 机制图中标出了坐标系和关键对象。
- [ ] 三维图不只“好看”，还展示了关键几何关系。
- [ ] 判据图说明了“为什么此时成立 / 不成立”。
- [ ] 轨迹图能看出时间方向或关键时刻。
- [ ] 优化结果图能看出约束边界或可行区域。
- [ ] 敏感性图覆盖了最可能被质疑的参数。

## 四、文件与排版

- [ ] 每张图保留源脚本。
- [ ] 每张图至少导出 `png` 和 `pdf/svg`。
- [ ] 文件名包含题号和图义，例如 `q2_03_radius_sensitivity.pdf`。
- [ ] 论文中引用的图文件和实际生成文件一致。
- [ ] 不把 MATLAB / Python 窗口截图直接塞进论文。

## 五、最后 2 小时快速判断

如果时间不够，优先保留：

1. 一张总流程 / 模型框架图。
2. 一张核心机制 / 几何判据图。
3. 一张主要结果图。
4. 一张方案对比图。
5. 一张敏感性或误差分析图。
