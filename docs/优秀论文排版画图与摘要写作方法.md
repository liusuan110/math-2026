## 一、优秀论文的整体观感

优秀论文给评委的第一印象通常不是“用了多高级的算法”，而是：

1. 第一页摘要能看出全文主线。
2. 第二到第四页能看出问题拆解、假设、符号和全文框架。
3. 每一问都有“问题分析 -> 模型建立 -> 求解结果 -> 检验或解释”的闭环。
4. 图表与公式是为了解释模型，不是堆满页面。
5. 结果数值醒目，且能和题目要求逐项对应。

从样本看，优秀论文的版面一般有三种风格：

| 风格 | 代表 | 优点 | 风险 |
|---|---|---|---|
| 国赛稳健型 | 2023 A 定日镜、2024 B 生产决策 | 摘要清楚，正文层级稳定，适合正式提交 | 如果图表少，会显得表达偏文字 |
| 数据分析型 | 2023 C 蔬菜补货 | 图表多，模型框架清楚，能展示数据工作量 | 信息过密，容易像技术堆叠 |
| 期刊压缩型 | 2023 B 多波束国二短文 | 双栏紧凑，摘要克制，公式表格集中 | 不一定适合国赛提交模板，正文空间紧 |

比赛最终论文建议采用“国赛稳健型”为主，吸收“数据分析型”的框架图和结果图表达，不建议照搬期刊双栏排版。

## 二、排版结构方案

### 1. 推荐全文结构

建议最终论文按以下结构组织：

1. 标题
2. 摘要
3. 关键词
4. 一、问题重述
5. 二、问题分析
6. 三、模型假设
7. 四、符号说明
8. 五、模型建立与求解
9. 六、模型检验与敏感性分析
10. 七、模型评价、推广与改进
11. 参考文献
12. 附录

其中第 5 部分“模型建立与求解”应按问题编号分节：

```text
5.1 问题一模型的建立与求解
5.1.1 数据预处理/几何关系/基础模型
5.1.2 模型求解
5.1.3 结果分析

5.2 问题二模型的建立与求解
...
```

不要把所有公式堆在“模型建立”里，也不要把所有结果堆到最后。每一问都要形成小闭环。

### 2. 前 4 页的任务

前 4 页不是铺垫，而是评委快速判断水平的区域。

| 页码 | 主要任务 | 建议内容 |
|---|---|---|
| 第 1 页 | 摘要 | 总方法、分问题方法、关键结果、关键词 |
| 第 2 页 | 问题重述 | 背景压缩，重点重述题目给出的任务和约束 |
| 第 3 页 | 问题分析 | 每问用 1-2 段说清“为什么这样建模” |
| 第 4 页 | 框架图/假设/符号 | 给出全文模型框架图，开始进入假设和符号 |

2023 C 上海二等奖论文在第 4 页给出“全文模型框架图”，效果很好：图中同时包含数据预处理、四个问题、所用模型和求解器，评委不需要翻到后文才知道全文路线。

### 3. 标题和小标题

标题要直接体现模型主线，不要过于口号化。

好标题特征：

- 包含题目对象。
- 包含核心方法。
- 包含决策目标或模型性质。

示例风格：

```text
基于蒙特卡洛光线追迹与双层规划的定日镜场优化设计模型
基于多目标规划的多波束测线布设模型
基于 ARIMA、残差修正与价格弹性的商超补货定价决策模型
基于抽样检验与 0-1 规划的生产过程最优决策模型
```

小标题要承担导航功能。优秀论文的小标题通常能让人只看目录就知道逻辑：

```text
5.1.1 定日镜法向向量模型的建立
5.1.2 余弦效率与大气透射率模型
5.1.3 光锥能流密度模型
5.1.4 阴影遮挡与截断效率模型
```

不推荐的小标题：

```text
问题一
模型一
结果
算法
```

这些标题信息太少，评委需要读正文才能知道你做了什么。

## 三、版面细节规范

### 1. 页面密度

优秀论文一般保持“文字、公式、图表”三者轮换，不让连续 2 页全是大段文字，也不让连续 2 页全是图。

建议：

- 摘要页可以纯文字，但要分段明确。
- 正文每 1-2 页至少出现一个图、表、公式或结果框。
- 公式密集页要穿插解释语句。
- 大表尽量放附录，正文只放汇总表。
- 关键结果表可以放正文，但要压缩列数。

### 2. 字体和字号

建议沿用国赛模板默认设置，不在比赛当天自行发明格式。

实用建议：

- 正文：宋体/SimSun 或模板默认中文字体。
- 英文和数字：Times New Roman 或模板默认英文字体。
- 一级标题：加粗，间距稳定。
- 图题表题：比正文略小，但必须清晰。
- 公式编号：右对齐，格式统一。
- 不要在正文里大量使用彩色文字。

### 3. 段落写法

优秀论文的段落通常遵循：

```text
本段要解决什么 -> 使用什么方法 -> 得到什么表达式/结果 -> 该结果服务下一步什么任务
```

示例结构：

```text
为计算某一测线的覆盖宽度，首先建立以海域中心为原点的二维剖面坐标系。根据波束开角与坡面倾角的几何关系，可得到左右覆盖宽度表达式。进一步结合相邻测线间距，定义重叠率指标。该指标将作为后续测线布设优化的主要约束。
```

不要写成：

```text
我们建立模型如下。然后求解。结果如下。
```

这种写法缺少“为什么”和“服务什么”的桥。

### 4. 符号表

符号表要早出现，且只放正文真的会频繁使用的符号。

建议列：

| 符号 | 说明 | 单位 |
|---|---|---|
| `x_i, y_i` | 第 i 个对象的位置坐标 | m |
| `D_i` | 第 i 条测线处水深 | m |
| `W_i` | 第 i 条测线覆盖宽度 | m |
| `eta_i` | 第 i 条测线与前一条测线重叠率 | - |

不要把只出现一次的临时变量都塞进符号表。符号表越长，越要保证后文不乱换符号。

## 四、图表方案

### 1. 图的分类

国赛论文中的图大致分 6 类，每类任务不同：

| 图类型 | 作用 | 典型位置 |
|---|---|---|
| 题意示意图 | 解释物理/几何场景 | 问题重述或问题分析 |
| 全文框架图 | 总览每问模型路线 | 问题分析末尾 |
| 模型机理图 | 解释变量关系或算法流程 | 模型建立 |
| 结果可视化图 | 展示求解结果 | 每问结果分析 |
| 对比检验图 | 证明模型有效 | 模型检验 |
| 灵敏度图 | 说明稳健性 | 模型评价 |

优秀论文不会把所有图都画成同一种图。每张图都要回答一个明确问题。

### 2. 必备图表清单

如果选 B 题，建议至少准备：

1. 题意几何示意图：坐标系、角度、距离、覆盖范围。
2. 算法流程图：从输入数据到求解结果。
3. 核心结果图：路径、布线、区域划分、决策树或流程。
4. 结果表：关键变量和目标函数值。
5. 灵敏度或误差图：展示参数变化对结果影响。

如果选 C 题，建议至少准备：

1. 数据处理流程图。
2. 全文模型框架图。
3. 趋势图：销量、价格、成本随时间变化。
4. 分布图：直方图、箱线图、品类对比柱状图。
5. 相关性图：热力图或聚类图。
6. 预测效果图：真实值 vs 预测值。
7. 优化结果表：补货量、定价、收益、选择结果。
8. 敏感性图：价格、成本、损耗率变化对收益影响。

### 3. 图表的优秀效果

#### A 题：简单示意图 + 公式解释

2023 A 定日镜论文中的阴影遮挡示意图很简单：红色入射光线、蓝色反射光线、黑色定日镜。它没有复杂配色，但一眼能解释“遮挡”发生在哪里。图后马上接光线追迹解释和效率公式，这种“图 -> 文字 -> 公式”的衔接很好。

可学习点：

- 示意图不必复杂，但要标清关键对象。
- 图后必须解释它和公式的关系。
- 图题要具体，如“阴影遮挡示意图”，不要只写“示意图”。

#### B 题：几何图与测线图

多波束工程中几何推导图、测线布设图、等深线图都很必要。它们分别服务三个问题：

- 几何图说明覆盖宽度公式从哪里来。
- 测线图说明布设结果是否全覆盖。
- 等深线/地形图说明复杂地形为何需要分块。

注意：部分工程图使用深色背景，嵌入论文后文字和坐标轴偏暗，线号也拥挤。比赛论文中建议重绘为白底、深色线条、少量高对比颜色。

#### C 题：全文框架图和预测流程图

2023 C 上海二等奖论文的全文框架图很值得学习：一张图把数据预处理、问题一到四、模型方法和求解器串起来。2023 C 机器学习路线还给出了 RFAN 模型结构图、预测流程图和训练损失图，能体现技术深度。

可学习点：

- 框架图必须按题目问题组织，不要按代码文件组织。
- 数据分析图要有“解释句”，不能只展示图。
- 预测图必须同时放真实值和预测值，最好标出误差。
- 优化结果最好用表格呈现，图只辅助说明趋势。

### 4. 画图风格建议

论文图统一遵守：

1. 白底优先。
2. 坐标轴、标题、图例都用中文，必要英文缩写保留。
3. 一张图最多 3-5 种颜色。
4. 避免彩虹色，除非是热力图或地形深度图。
5. 线宽、字体、图例大小全篇统一。
6. 图导出优先 `pdf/svg`，同时备份 `png`。
7. 位图建议 300 dpi 以上。
8. 图题放在图下，表题放在表上。
9. 正文必须引用每一张图，如“如图 3 所示”。
10. 不要出现截图式图表，Excel 表也要重排。

### 5. Python 绘图建议

建议给所有绘图脚本统一风格：

```python
import matplotlib.pyplot as plt

plt.rcParams.update({
    "font.sans-serif": ["SimSun", "Microsoft YaHei"],
    "axes.unicode_minus": False,
    "figure.dpi": 150,
    "savefig.dpi": 300,
    "axes.linewidth": 0.8,
    "font.size": 10,
})
```

常用尺寸：

```text
单栏图：宽 7-8 cm，高 5-6 cm
通栏图：宽 14-16 cm，高 8-10 cm
框架图：宽 14-16 cm，高 9-12 cm
```

导出建议：

```python
plt.tight_layout()
plt.savefig("figures/xxx.pdf", bbox_inches="tight")
plt.savefig("figures/xxx.png", bbox_inches="tight", dpi=300)
```

### 6. 表格方案

表格适合放：

- 题目给定参数整理。
- 符号说明。
- 模型结果。
- 多方案对比。
- 敏感性分析数值。

优秀表格的特点：

1. 列名短。
2. 单位写在表头。
3. 小数位统一。
4. 关键结果加粗或在正文强调。
5. 不把原始大数据表塞进正文。

建议：

- 正文表格不超过页面宽度。
- 如果列太多，转置成“指标-数值”表。
- 如果行太多，放附录，正文只放汇总。

## 五、摘要写作方法

摘要是整篇论文最重要的一页。评委会先通过摘要判断：

1. 你有没有读懂题。
2. 你的方法是否成体系。
3. 你是否真的算出了结果。
4. 你的创新点在哪里。
5. 你的论文是否值得继续细读。

### 1. 摘要的标准结构

建议采用“五段式摘要”：

```text
第一段：总述题目对象、总体建模思路和核心目标。

第二段：针对问题一，说明使用什么方法，解决什么子任务，得到什么关键结果。

第三段：针对问题二，说明如何在问题一基础上建模，目标函数和约束是什么，得到什么策略/结果。

第四段：针对问题三/四，说明如何扩展模型，处理新增约束或不确定性，给出主要结果。

最后一行：关键词。
```

如果有四问，就写“针对问题一/二/三/四”。如果某问很短，可以合并，但不要让摘要变成一整段。

### 2. 摘要第一段怎么写

第一段要回答“本文整体做了什么”，不能直接进入细节。

通用句式：

```text
本文针对【题目对象】中的【核心决策/计算问题】，在分析【关键影响因素】的基础上，建立了【核心模型 1】和【核心模型 2】，并以【优化目标】为准则给出【最终方案】。模型首先用于【基础评价/预测】，随后嵌入【优化/仿真/规划】过程，实现了【题目要求的核心结果】。
```

B 题示例句：

```text
本文针对多波束测深中的测线布设问题，基于空间解析几何建立覆盖宽度与重叠率计算模型，并将测线总长度、漏测面积和过度重叠作为评价指标，构建多目标优化布设模型，给出满足重叠率约束的测线方案。
```

C 题示例句：

```text
本文针对生鲜商超蔬菜类商品的补货与定价决策问题，在完成销售数据清洗和相关性分析的基础上，建立销量预测模型与收益最大化优化模型，分别给出品类层面未来一周补货定价策略和单品层面选择方案。
```

### 3. 分问题段怎么写

每个分问题段建议包含四个要素：

```text
任务 -> 方法 -> 结果 -> 承接
```

模板：

```text
针对问题一，首先【做了什么预处理/建了什么基础模型】；然后【采用什么方法计算/分析】；最终【得到什么核心指标/规律/结论】。该结果为后续【问题二/优化模型】提供了【参数/评价函数/约束依据】。
```

示例：

```text
针对问题一，首先对附件销售数据按日期、品类和单品进行聚合，并剔除长期无销售记录的异常单品；随后利用描述性统计、箱线图和 Pearson 相关系数分析不同品类及单品的销售分布与相互关系。结果表明，花叶类销量占比最高，部分品类之间存在显著正相关关系，为后续需求预测和补货优化提供了数据依据。
```

### 4. 摘要必须写结果

优秀摘要一定写结果，不只写方法。

结果可以包括：

- 最优目标函数值。
- 关键参数取值。
- 预测误差。
- 总收益。
- 测线总长度。
- 漏测率。
- 样本量。
- 决策方案。

对比：

```text
弱：本文建立了整数规划模型，求得最优补货策略。
强：本文建立 0-1 整数规划模型，在可售单品数 27-33 和最小陈列量 2.5 kg 约束下，确定了 7 月 1 日的单品选择、补货量和定价方案，使预测收益达到 XXX 元。
```

如果比赛时结果还不完美，也要写“可交付结果”：

```text
得到一组满足约束的可行布设方案，测线总长度为 XXX 海里，漏测率为 XXX%，过度重叠长度为 XXX 海里。
```

### 5. 摘要里的模型名如何处理

模型名不是越多越好。摘要里模型名应服务逻辑。

建议：

- 基础统计方法可以少写或合并写。
- 核心创新模型必须写。
- 求解器名字只有在重要时才写。
- 不要把所有包名、算法名堆进一句话。

例如 C 题可以写：

```text
采用 ARIMA 建立销量基准预测，并利用残差修正模型提高短期预测精度。
```

比下面这样更稳：

```text
采用 ARIMA、LSTM、RFAN、GRU、K-means、Pearson、Spearman、SLSQP、BONMIN 等方法进行求解。
```

后一种看起来强，但评委可能觉得主线不清。

### 6. 摘要关键词

关键词建议 4-6 个，覆盖：

1. 题目对象。
2. 核心模型。
3. 求解方法。
4. 目标或评价指标。

示例：

```text
关键词：多波束测深；空间解析几何；多目标规划；覆盖率；灵敏度分析
关键词：自动定价；销量预测；价格弹性；混合整数规划；收益最大化
关键词：抽样检验；0-1 规划；生产决策；遗传算法；敏感性分析
```

不要把关键词写成过泛的词：

```text
数学建模；优化；Python；数据分析
```

这些词对评委没有信息量。

## 六、优秀摘要的效果分析

### 1. 2023 A 定日镜摘要

优点：

- 标题明确：定日镜场优化设计模型。
- 第一段先给总路线：蒙特卡洛光线追迹、效率计算、双层规划优化。
- 每问都写了方法和数值结果。
- 关键结果如 `61.58%`、`37.629MW`、`0.599kW/m2` 醒目。
- 关键词覆盖方法和对象。

可学习：

- A 题摘要一定要写物理指标结果。
- 如果第一问是评价模型，第二三问是优化，摘要要显式写“先评价后优化”。

### 2. 2023 C 机器学习路线摘要

优点：

- 开头直接提出销量受三类因素影响：自回归性、互相关性、价格弹性。
- 模型链条完整：ARIMA -> LSTM 残差拟合 -> 价格弹性 -> 整数规划。
- 每问都有明确动作。
- 能体现模型创新。

风险：

- 模型名较多，摘要信息密度很高。
- 如果正文和代码支撑不足，容易被认为“堆模型”。

可学习：

- C 题冲奖可以在摘要第一段先提出“影响因素分解”，再引出模型。
- 模型多时，要用“谁负责什么”串起来，而不是并列罗列。

### 3. 2024 B 生产决策摘要

优点：

- 分问题层次非常清晰。
- 问题一写出样本量和接收/拒收阈值。
- 问题二三写出 0-1 决策、非线性整数规划、贪心和遗传算法。
- 问题四把抽样估计和前面模型闭环。

可学习：

- B 题摘要必须把决策方案写具体。
- 对生产、检测、库存、资源配置类题，摘要中要写“目标函数”和“决策变量”。

### 4. 2023 B 多波束短文摘要

优点：

- 文字克制，直接说明“覆盖宽度与重叠率是评价指标”。
- 方法和题目对象绑定紧密：解析几何、多目标规划、真实海域。
- 中英文摘要结构规范。

风险：

- 期刊式摘要没有分问题写法，国赛提交时可能不如“针对问题一/二/三”清晰。

可学习：

- B 题如果题目有明确指标，应在摘要第一段就定义这些指标。

## 七、比赛当天摘要写作流程

建议最后一天上午按以下流程完成摘要：

1. 列出每问最终交付物。
2. 每问写一句“方法 + 结果”。
3. 补第一段总述。
4. 把关键数字补进去。
5. 删除不能被正文支撑的模型名。
6. 检查关键词。
7. 检查摘要是否不超过一页。

## 八、最终提交前排版检查清单

### 摘要检查

- 是否一页内完成。
- 是否每问都有方法。
- 是否每问至少有一个结果或结论。
- 是否出现关键数值。
- 是否删除了正文没有支撑的夸张说法。
- 关键词是否 4-6 个。

### 图表检查

- 每张图是否在正文中被引用。
- 图题是否具体。
- 坐标轴是否有单位。
- 图中文字是否打印后可读。
- 是否存在深色背景导致看不清。
- 同类图的颜色、字体、线宽是否一致。
- 结果表小数位是否统一。

### 正文检查

- 每一问是否有“分析 -> 建模 -> 求解 -> 结果”。
- 公式是否编号统一。
- 符号是否前后一致。
- 结果是否逐项回应题目要求。
- 模型检验是否至少有一处。
- 附录是否能对应代码和结果文件。

## 十、一句话总结

优秀论文的摘要负责“让评委愿意继续读”，排版负责“让评委读得不累”，图表负责“让模型不只停留在文字和公式里”。比赛时不要追求花哨版面，要追求第一页清楚、每问闭环、图表统一、结果醒目。
