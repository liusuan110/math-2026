### 组队与报名【官方】
- 每队 **1–3 名大学生**，鼓励（但不强制）不填指导教师。
- ❗ **"三人必须同校、专业不限"这一说法未通过核验**（投票 1-2 驳回），具体同校/年级/研究生分组限制请查官方须知。
- 报名、下载赛题、提交作品全部通过官方管理系统 **https://cumcm.cnki.net** 完成。

### 提交格式【官方】
- 需**同时提交纸质版 + 电子版**；作品 = **参赛论文（必需）+ 支撑材料（可选）**。
- 论文固定三段式结构：
  1. **第 1 页**：承诺书
  2. **第 2 页**：编号专用页
  3. **第 3 页**：摘要专用页（**页码从这页起，用阿拉伯数字编为第 1 页**）
  4. **第 4 页起**：正文
- **摘要**：含标题与关键词，原则上**不超过 1 页**，**无需英文**。摘要是评审第一眼，权重极高。
- **正文**：**不超过 30 页**（⚠️ 2026 新规，2025 是"尽量 20 页内"——别用旧数据），**不要目录**。
- **附录**：页数不限。
- **文件**：PDF 或 Word 之一；建议**非图片 PDF**（可复制文字）；**单文件 ≤ 20MB**。
- **电子版特别注意**：电子版论文**不能含承诺书和编号页**（电子版第一页就是摘要页）；支撑材料用 WinRAR 压成**单个 ZIP 或 RAR**（同样 ≤ 20MB）。

## 2. 题型特点与选题策略

### 四大类题型【经验】（社区常用分类，非官方唯一口径）
| 类别 | 内核 | 常用方法 |
|------|------|----------|
| **评价类** | 给对象打分/排序 | AHP、熵权、TOPSIS、模糊综合评价、灰色关联 |
| **运筹优化类** | 求最优方案/调度 | 线性/整数/非线性规划、目标规划、启发式算法 |
| **预测类** | 由历史推未来 | 回归、时间序列(ARIMA)、灰色 GM(1,1)、神经网络 |
| **机理分析类** | 用物理/数学机理建模 | 微分方程、动力学、数值仿真 |

### A / B / C 三题定位
- **A 题（连续/物理建模）**【官方真题印证】：偏物理、力学、工程优化，需较强**数学推导**能力（微分方程、优化、数值计算）。例：2022 波浪能装置、2023 定日镜场。
- **B 题（离散/优化运筹）**：偏建模 + 算法设计 + 求解，综合性强。例：2022 无人机编队、2024 生产过程决策。
- **C 题（数据分析）**：数据量大、上手门槛低、编程与数据处理为主。例：2023 蔬菜定价补货、2024 农作物种植策略。**最适合入门队首选**。

### 现场选题策略【经验】（medium 置信，2-1 票）
- **扬长避短**：数学功底强 → A；编程/数据处理强 → **C**；综合能力强 → B。
- 入门队建议：**优先 C 题**（结果易出、易拿国奖基础分），除非队里有很强的数学/物理选手再考虑 A。
- 开赛后**三题都通读 1–2 小时**再定，别冲动。看：数据是否够、模型是否想得出第一问、三天能否做完。
- ⚠️ 别选"看起来高大上但第一问都卡住"的题——能完整做完 + 写清楚，胜过半成品的难题。

## 3. 核心模型与算法清单（按场景查）

> 入门队不必全会，**先吃透"评价 + 优化 + 预测"三族**，覆盖 C/B 题大半。

| 方法族 | 典型方法 | 什么时候用 | Python 库 |
|--------|----------|-----------|-----------|
| **综合评价** | AHP 层次分析、熵权法、TOPSIS、模糊综合、灰色关联 | "给方案打分/排名/选最优" | numpy、自写权重 |
| **数学规划** | 线性/整数/非线性/目标规划 | "在约束下求最优(最大利润/最小成本)" | `scipy.optimize`、`pulp`、`cvxpy`、gurobi |
| **预测** | 线性/多元回归、ARIMA、灰色 GM(1,1)、指数平滑 | "由历史数据预测未来值" | `statsmodels`、`sklearn` |
| **分类/聚类/降维** | KMeans、层次聚类、KNN、SVM、PCA、判别分析 | "分组/识别类别/特征压缩" | `sklearn` |
| **微分方程/机理** | ODE/PDE 建模、数值解、动力学（如 SIR、人口模型） | A 题机理、传播/增长/物理过程 | `scipy.integrate`、`sympy` |
| **图论与网络** | 最短路、最小生成树、最大流、TSP、复杂网络 | "路径/连接/调度/网络结构" | `networkx` |
| **启发式优化** | 模拟退火、遗传算法、粒子群 | 规划求解器搞不定的大规模/非凸问题 | `scipy`、`deap`、自写 |
| **随机模拟** | 蒙特卡洛、随机仿真 | "含不确定性/难解析，靠抽样估计" | `numpy.random` |
| **机器学习** | 随机森林、XGBoost、神经网络 | C 题大数据预测/分类，作为增强手段 | `sklearn`、`xgboost`、`pytorch` |
| **数据预处理（必备）** | 缺失值、异常值、归一化、相关性分析 | 几乎每道题第一步 | `pandas`、`numpy` |
| **灵敏度分析（必备）** | 参数扰动、稳健性检验 | 论文必有的一节，体现严谨 | 自写循环 + 绘图 |

## 4. Python 工具栈与代码套路

核心栈（Datawhale《数学建模导论·Python》逐节验证可用）：

| 库 | 用途 |
|----|------|
| `numpy` | 线代、矩阵、数值计算底座 |
| `pandas` | 数据读取/清洗/透视（C 题主力） |
| `scipy` | 优化(`optimize`)、积分/ODE(`integrate`)、插值、统计 |
| `sympy` | 符号运算、解析解微分方程 |
| `statsmodels` | 回归、ARIMA、统计检验 |
| `scikit-learn` | 分类/聚类/回归/PCA |
| `pulp` / `cvxpy` | 线性/整数/凸规划建模求解 |
| `networkx` | 图论与网络建模 |
| `matplotlib` / `seaborn` | 出图（论文配图主力） |
| `xgboost` / `pytorch` | 进阶预测/神经网络 |

**比赛代码套路**：
1. 一个 `notebook` 探索数据 + 一套 `.py` 脚本出最终结果，分开放（已在工作区 `code/`）。
2. 每问一个脚本/cell，输出图存 `figures/`、结果存 `data/`，文件名带问题号。
3. 绘图统一风格（中文字体、字号、dpi≥300），论文里图表必须有**编号 + 标题 + 坐标轴单位**。
4. ⚠️ 入门队建议**纯 Python**即可；但注意：部分经典教材/课程用 MATLAB/LINGO/SPSS，迁移时留意差异（详见来源 caveat）。gurobi 需学术许可证，建议先用 `pulp`/`scipy` 兜底。

## 5. 论文写作与排版

### 写作要点
- **摘要（最重要）**：1 页内讲清"**问题→方法→关键结果(带数字)→结论**"。评委先看摘要定档次。每问都要有**具体量化结论**，不要只说"建立了模型"。
- **结构**（每问闭环）：问题重述 → 问题分析 → 模型假设 → 符号说明 → 模型建立 → 模型求解(含结果) → **结果分析 + 灵敏度/检验** → 模型评价(优缺点)。
- **图表**：图要清晰可读、有编号标题；表格三线表；公式用编号。"一图胜千言"，但别堆无关图。
- **可复现**：附录放完整代码；正文引用结果要能对上。

### 排版模板（工作区已备）
- **LaTeX**：`templates/CUMCMThesis/`（latexstudio，~932★，含 `cumcmthesis.cls`）。⚠️ 适配的是 **2023 格式**，是**社区非官方**模板——用前**自查与 2026 规范的差异**（正文 30 页、摘要起页码、电子版去承诺书等）。
- **Typst**：`templates/cumcm-typst/`（cumcm-muban）。同样需对照官方规范核对。

### 评阅规律【部分为经验】
- 摘要 + 完整性 + 结果合理性 + 写作清晰度是基础盘；创新是加分项。
- ⚠️ 官方**评分维度的具体权重**本轮未找到权威量化来源（见"待确认"）。经验上：**先保完整与规范，再谈创新**。

## 6. 三人分工与三天时间管理【经验】

### 分工（一人多角，互相补位）
- **建模手**：读题、定模型、推公式（数学最强者）。
- **编程手**：写代码、求解、出图（Python 最强者）。
- **写作手**：搭论文框架、写摘要正文、排版（文字 + 责任心强者）。
- 三人都要懂全局；写作手从第一天就开始写，**不要最后一天才动笔**。

### 三天节奏（参考）
- **Day 1**：通读三题(1–2h)→选题→第一问建模+跑通→当天写完问题重述/假设/符号/第一问初稿。
- **Day 2**：主攻第二、三问（通常最难/最核心）→边做边写→晚上对齐进度，砍掉做不完的支线。
- **Day 3 上午**：收尾最后一问 + 灵敏度/检验 + 模型评价。
- **Day 3 下午**：**全力打磨摘要 + 通读排版 + 查格式**，预留 ≥2h 走完整提交流程（MD5、压缩、上传），别卡点。
- 通则：**先求完整，再求深入**；任何时候手上都要有"能交的版本"。
