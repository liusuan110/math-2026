## 一、A 题建模手法

### 1. 2023 A 定日镜场优化：物理机理拆解 + 蒙特卡洛 + 参数化优化

题目要求可以拆成三层：

1. 已知镜场参数，计算年平均光学效率、年平均输出热功率、单位镜面面积输出热功率。
2. 在额定功率约束下，所有定日镜尺寸和安装高度相同，优化塔位置、镜子数量、位置、尺寸和高度。
3. 放开尺寸和高度差异，继续提升单位面积输出功率。

该工程的建模翻译方式很清晰：

| 题目要求 | 建模翻译 |
|---|---|
| “计算光学效率” | 把总效率分解为余弦效率、大气透射率、阴影遮挡效率、截断效率等子效率 |
| “太阳光不是完全平行” | 用二维正态分布描述光锥能流密度，用随机光线模拟非平行入射 |
| “反射到集热器” | 建立镜场三维坐标系，计算太阳入射向量、反射向量和定日镜法向量 |
| “阴影遮挡、截断损失” | 用蒙特卡洛光线追迹统计被遮挡、未命中集热器的光线比例 |
| “优化镜场布局” | 先用同心圆密排布局减少自由度，再做双层规划和控制变量遍历 |
| “问题三更自由” | 把尺寸、高度设计成同心圆半径的函数，既增加自由度，又避免完全无结构搜索 |

核心手法：

- 物理量分解：把一个“效率”拆成多个可计算效率因子。
- 坐标几何建模：用三维坐标、向量和反射定律表达光路。
- 蒙特卡洛模拟：对无法简单解析的遮挡、截断问题，用大量随机光线统计概率。
- 参数化布局：用同心圆、镜间距、圈半径等结构化参数代替每面镜子的自由坐标。
- 双层规划：上层确定吸收塔位置，下层优化镜场参数，再反馈迭代。
- 先评估后优化：第一问先建立可计算评价器，第二三问把评价器嵌入优化。

这套方法适用于 A 题中的工程物理问题。遇到“效率、功率、能耗、覆盖、流量、受力、轨迹”等对象时，应优先考虑：

1. 先找物理守恒或几何关系。
2. 把复杂指标拆成可计算子指标。
3. 对难解析的局部过程做仿真或随机统计。
4. 对高维优化变量做结构化降维。

### 2. 2024 A “板凳龙”：参数曲线 + 约束求根 + 碰撞检测 + 路径优化

题目要求本质上是动态几何仿真：

1. 给定等距螺线和龙头速度，输出每秒所有把手的位置与速度。
2. 找到不碰撞的最晚盘入时刻。
3. 求能进入 9 m 调头圆的最小螺距。
4. 设计由两段相切圆弧组成的 S 形调头路径，并尝试缩短。
5. 在所有把手速度不超过 2 m/s 的条件下，求龙头最大速度。

该工程的建模翻译方式：

| 题目要求 | 建模翻译 |
|---|---|
| “沿等距螺线运动” | 用阿基米德螺线参数方程表示路径 |
| “龙头速度恒定” | 用弧长和时间关系反推出龙头当前参数角 |
| “相邻板凳通过把手连接” | 相邻把手之间距离固定，逐节用非线性方程求根 |
| “每秒位置与速度” | 每秒求全部把手坐标，速度用短时间差分近似 |
| “不能碰撞” | 将板凳视为线段或矩形，检测非相邻板凳几何相交 |
| “最小螺距、最短调头曲线” | 把螺距、圆弧半径、切点等作为优化变量，用数值优化求解 |
| “最大速度” | 先建立速度传递模型，再按比例或搜索找到约束边界 |

核心手法：

- 参数曲线建模：复杂运动路径先转成参数方程。
- 链式约束求解：龙头位置确定后，后续把手由固定距离递推求根。
- 仿真表格化：题目要求 Excel 输出，代码直接按秒生成完整表。
- 几何碰撞检测：用线段相交、矩形包络或距离阈值判断不可行时刻。
- 约束边界搜索：终止时刻、最小螺距、最大速度都不是直接求“最优”，而是在找可行域边界。

这套方法适用于 A 题中的运动、轨迹、机器人、车辆、队列、机构运动问题。关键是先把对象变成“路径参数 + 约束方程 + 可行性判定器”，再做仿真或搜索。

## 二、B 题建模手法

### 1. 2023 B 多波束测线：解析几何 + 覆盖约束 + 多目标规划

题目要求：

1. 在二维坡面上计算不同测线位置的覆盖宽度和相邻重叠率。
2. 考虑测线方向与坡面法向夹角，在三维矩形坡面上计算覆盖宽度。
3. 在给定矩形海域中布设测线，使测线尽可能短，同时满足重叠率 10%-20%。
4. 对真实海域复杂地形布设测线，要求给出总长度、漏测率、过度重叠等评价。

两个 2023 B 工程采取的共同思路是：先把声呐覆盖问题化为几何覆盖宽度问题，再把测线布设化为带约束的路径规划问题。

| 题目要求 | 建模翻译 |
|---|---|
| “覆盖宽度” | 用水深、波束开角、坡度角推导左右覆盖宽度 |
| “重叠率” | 用相邻条带交叠长度除以覆盖宽度，作为约束指标 |
| “测线方向不同” | 定义等效坡度，把三维问题转成二维坡面问题 |
| “矩形海域布线” | 从深水侧到浅水侧递推生成测线位置，保持目标重叠率 |
| “真实海底地形” | 对海底点云或栅格做局部平面拟合，分区复用坡面模型 |
| “总长度最小、漏测小、过重叠少” | 构成多目标规划或多指标评价体系 |

核心手法：

- 二维解析几何：先在最简单剖面上推公式。
- 三维到二维等效化：测线方向影响通过等效坡度吸收。
- 递推布线：不是一次性求所有测线，而是从边界出发，根据上一条测线的覆盖宽度和目标重叠率确定下一条。
- 分块拟合：真实地形不是单一坡面，就用最小二乘平面分块近似。
- 栅格评价：把海域离散成网格，统计漏测面积和过度重叠长度。
- 灵敏度分析：用 Sobol 等方法说明哪些参数对结果影响最大。

特别值得学习的是 `2023-B-multibeam-survey/` 的 ARPF 思路：

1. 对整个海域做平面拟合。
2. 如果拟合误差过大，就递归分成更小区块。
3. 每个区块提取局部坡度和方向。
4. 区块内按等高平行测线布设。
5. 全局合并测线，并计算总长度、漏测率、过度重叠。

这是一种很通用的“复杂空间问题分块线性化”策略。遇到 B 题中地图、地形、空间覆盖、路径布设、巡检路线、传感器布点问题时，可以优先考虑它。

### 2. 2024 B 生产过程决策：抽样检验 + 0-1 决策 + 成本收益优化

题目要求：

1. 供应商声称次品率不超过标称值，设计检测次数尽可能少的抽样方案。
2. 已知零配件、半成品、成品次品率，决定是否检测零件、是否检测成品、是否拆解不合格品。
3. 推广到多道工序、多零配件的生产过程。
4. 当次品率来自抽样估计时，重新给出决策方案。

该类工程的建模翻译：

| 题目要求 | 建模翻译 |
|---|---|
| “检测次数尽可能少” | 用二项分布或正态近似设计最小样本量 |
| “95%/90% 信度” | 转成单侧假设检验或置信区间判别规则 |
| “是否检测/是否拆解” | 定义二进制决策变量 |
| “成本、售价、调换损失、拆解费用” | 分阶段建立成本项和收益项 |
| “不同情形给具体方案” | 参数表驱动，同一模型循环求 6 种情形 |
| “多工序多零件” | 把每道工序看作问题二的子问题，逐层传递次品率和成本 |
| “次品率由抽样得到” | 先估计和检验次品率，再带入优化模型；或做敏感性/稳健性分析 |

核心手法：

- 抽样检验模型：二项分布、正态近似、Cochran 样本量公式、单侧判别。
- 0-1 决策建模：检测与否、拆解与否天然是二进制变量。
- 分阶段成本分解：购买成本、检测成本、装配成本、拆解成本、退换损失、销售收益。
- 非线性整数规划或 MILP：根据成本公式复杂度选择求解器。
- 贪心与遗传算法：多工序情况下，先用逐层贪心得到可行解，再用遗传算法搜索更优组合。
- 敏感性分析：改变次品率、检测成本、调换损失等参数，看决策是否稳定。

该题的启发很强：B 题如果出现“是否做某项动作”“多阶段流程”“成本收益权衡”“风险检测”，通常第一反应应该是：

1. 把动作转成 0-1 变量。
2. 把流程拆成阶段成本。
3. 把风险参数先估计，再嵌入优化。
4. 用枚举、整数规划、启发式算法做求解对照。

### 3. 2020 B 穿越沙漠：状态转移 + 动态规划 + 记忆化搜索 + 博弈仿真

题目是沙漠生存游戏，玩家需要在天气、负重、资金、水、食物、村庄、矿山、终点等约束下选择路径和补给策略。

工程中的建模翻译：

| 题目要求 | 建模翻译 |
|---|---|
| “每天行动和消耗” | 把每天作为阶段，天气决定水和食物消耗 |
| “资金和负重限制” | 状态变量包含水、食物、资金、位置、天数 |
| “起点采购策略” | 对初始水和食物进行外层枚举 |
| “移动、停留、挖矿、补给” | 定义动作集合，形成状态转移方程 |
| “村庄补给选择太多” | 采用“先使用后记账”的补给策略减少搜索量 |
| “天气不确定、多玩家” | 用马尔可夫状态转移和蒙特卡洛模拟风险偏好 |

核心手法：

- 动态规划：阶段为天数，状态为位置和资源组合，目标为最终剩余资金最大。
- 记忆化搜索：避免重复计算同一状态。
- 剪枝：资源缺口无法补足、负重超限、资金不足时停止递推。
- 外层枚举 + 内层 DP：初始采购决策单独搜索，路径决策由 DP 解决。
- 不确定性仿真：天气或多玩家行为不确定时，用蒙特卡洛模拟观察收益分布。
- 博弈建模：引入风险偏好，模拟多玩家在冲突点的不同选择。

这类方法适合路线规划、库存消耗、补给策略、任务调度、游戏规则优化。B 题常见的“规则复杂但数学公式不深”的题，很可能靠状态设计和剪枝取胜。

## 三、C 题建模手法

### 1. 2023 C 蔬菜补货定价：数据分析 + 预测 + 收益优化

题目要求：

1. 分析不同品类、不同单品销售量的分布规律和相互关系。
2. 以品类为单位，给出未来一周日补货总量和定价策略，使收益最大。
3. 在单品数 27-33、最小陈列量 2.5 kg 等约束下，给出 7 月 1 日单品补货量和定价。
4. 说明还需要采集哪些数据。

两套 2023 C 工程都采用“先数据洞察，再预测，再优化”的总路线，但模型复杂度不同。

#### 路线 A：ARIMA + LSTM 残差修正 + 价格弹性 + 0-1 整数规划

`2023-C-vegetable-pricing/` 的核心手法：

| 题目要求 | 建模翻译 |
|---|---|
| “销售量分布规律” | 时间序列分解、趋势/季节性分析、描述性统计 |
| “相互关系” | Spearman 相关、热力图、R 型层次聚类 |
| “未来销量预测” | 先用 ARIMA 建基准预测，再用 LSTM 拟合残差 |
| “定价影响销量” | 引入价格弹性，对预测销量进行二次残差修正 |
| “收益最大” | 将销售量表示为成本利润率函数，求收益函数最大值 |
| “单品数量限制” | 用 0-1 整数规划选择单品 |

它的亮点是“预测模型级联”：

1. ARIMA 负责时间序列自回归部分。
2. LSTM/RFAN 负责拟合 ARIMA 未解释的残差。
3. 价格弹性负责把定价决策反作用到销量上。
4. 整数规划负责把预测收益落到单品选择。

这种路线适合想冲击更强模型创新的 C 题，但风险是代码量和调参成本高，需要能在比赛时间内稳定复现。

#### 路线 B：描述性统计 + 线性回归 + ARIMA/GRU + SLSQP/BONMIN

`2023-C-vegetable-pricing-shanghai-second/` 的核心手法：

| 题目要求 | 建模翻译 |
|---|---|
| “品类/单品分布规律” | 分类汇总、交叉分析、直方图、箱线图、描述性统计 |
| “相互关系” | Pearson 相关、K-means 聚类 |
| “品类补货和定价” | 线性回归拟合销售量与成本加成定价关系 |
| “未来一周” | ARIMA 预测未来成本加成定价或相关时间序列 |
| “收益最大” | 以补货量和定价为变量，建立非线性优化，用 SLSQP 求解 |
| “单品级选择” | 引入 0-1 变量，建立混合整数非线性规划，用 BONMIN 求解 |
| “未来单品成本” | 用 GRU/RNN 做成本预测 |

这条路线更“竞赛稳健”：统计分析容易解释，优化模型紧扣题目约束，机器学习只承担预测部件，不压过主线。

### 2. C 题的通用解题模板

C 题通常是“数据驱动决策题”，优秀工程基本都按如下链路推进：

1. 数据预处理：统一日期、单品编码、品类、退货、折扣、损耗、成本和销售额。
2. 描述性分析：先回答题目第一问，不急着预测。图表包括趋势图、箱线图、热力图、聚类图。
3. 关系建模：建立销量与价格、成本、时间、品类之间的关系。
4. 预测模块：用 ARIMA、指数平滑、回归、LSTM/GRU 等预测未来销量或成本。
5. 决策变量：品类层面通常是补货量和定价；单品层面还要加入是否选择。
6. 目标函数：收益最大、成本最小、损耗最小或综合目标。
7. 约束条件：销售空间、单品数量、最小陈列量、需求满足、库存不可为负。
8. 求解算法：连续变量用 SLSQP 等非线性优化；0-1 选择用整数规划；复杂非线性混合问题用启发式或专用求解器。
9. 稳健性：做误差分析、敏感性分析，或给出额外数据采集建议。

## 四、跨题型共性方法库

### 1. 题目要求到模型的翻译规则

| 题目措辞 | 常见模型动作 |
|---|---|
| 计算效率、功率、覆盖宽度 | 物理/几何公式，指标分解 |
| 优化设计、最大化、最小化 | 定义目标函数和约束条件 |
| 是否检测、是否选择、是否拆解 | 0-1 决策变量，整数规划 |
| 路径、测线、轨迹、盘入盘出 | 参数曲线、递推、碰撞检测、路径规划 |
| 分布规律、相互关系 | 描述性统计、相关性、聚类、时间序列分解 |
| 未来一周、预测需求 | ARIMA、回归、机器学习预测 |
| 复杂地形、复杂空间 | 分块、局部拟合、栅格化评价 |
| 信度、抽样、次品率 | 二项分布、假设检验、置信区间 |
| 风险、不确定、随机 | 蒙特卡洛、敏感性分析、稳健优化 |

### 2. 优秀工程的共同建模节奏

优秀工程很少一上来就堆复杂算法。它们通常遵循以下节奏：

1. 第一问建立“评价器”：能计算效率、覆盖、收益、损耗、风险等核心指标。
2. 第二问把评价器嵌入优化：变量、目标函数、约束条件开始完整出现。
3. 第三问增加真实约束：单品数量、调头空间、多工序、复杂地形、可变尺寸等。
4. 第四问做推广或稳健性：补充数据、未知参数、误差检验、敏感性分析。

这说明比赛中最重要的是把前一问的模型沉淀成可复用模块，而不是每问重写一个完全不同的模型。

### 3. 高质量模型的三个特征

第一，模型有“题目对象感”。

例如定日镜题不只是套优化算法，而是先把太阳角、反射向量、截断效率建出来；多波束题不只是路径规划，而是先推覆盖宽度和重叠率；蔬菜题不只是机器学习预测，而是先回答销售分布和相互关系。

第二，模型能落到代码。

优秀工程都把变量、约束、目标函数做成可计算对象。论文中的公式和代码中的函数可以互相对照：覆盖宽度函数、收益函数、成本函数、状态转移函数、碰撞判定函数。

第三，模型有检验和解释。

常见检验包括：

- 几何模型用另一种推导方式交叉验证。
- 预测模型用误差、残差、拟合图验证。
- 优化结果用敏感性分析说明稳定性。
- 仿真模型用多次模拟统计分布。
- 复杂空间模型用漏测率、过重叠率等指标评价。

## 五、对今年 B/C 选题的直接建议

### 如果选择 B 题

优先准备这几类手法：

1. 几何建模：坐标系、向量、距离、角度、覆盖、碰撞、相交。
2. 递推或动态规划：适合逐步布线、逐日决策、多阶段流程。
3. 0-1/整数规划：适合是否选择、是否检测、是否执行某动作。
4. 多目标优化：适合长度、成本、覆盖、风险之间权衡。
5. 分块线性化：适合复杂地形、复杂区域、空间异质性。

比赛时可采用的 B 题工作流：

1. 当晚先把题目中的“硬约束”全部圈出来。
2. 把每个动作或设计量命名为变量。
3. 先做一个能计算核心指标的函数。
4. 用小样例验证公式正确。
5. 再做优化和灵敏度分析。

### 如果选择 C 题

优先准备这几类手法：

1. 数据清洗和聚合：日期、类别、单品、退货、异常值、缺失值。
2. 描述性统计：箱线图、趋势图、相关热力图、聚类图。
3. 预测模型：ARIMA、回归、随机森林、LSTM/GRU 作为备选。
4. 收益优化：补货量、定价、是否选择单品。
5. 约束翻译：数量限制、最小订购量、库存、需求满足、损耗率。

比赛时可采用的 C 题工作流：

1. 第一问必须扎实做图和统计，给后续模型找依据。
2. 第二问用“预测 + 优化”承接，避免只预测不决策。
3. 第三问把单品选择转成 0-1 变量，不要只凭排序挑商品。
4. 第四问写成模型闭环：说明新数据如何进入预测、约束或目标函数。
