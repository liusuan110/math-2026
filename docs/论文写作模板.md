## 一、2026 格式合规结论（已对照官方《论文格式规范 2026 修订稿》核对）

| 规范要点 | 官方 2026 要求 | 两套模板是否满足 |
|---|---|---|
| 正文页数 | **≤ 30 页**（2025 是"尽量 20 页内"，已变） | ✅ 自己控制篇幅即可 |
| 摘要 | **≤ 1 页**，含标题与关键词，**无需英文** | ✅ 骨架已含关键词位 |
| 目录 | **不要目录** | ✅ 骨架默认不放目录（LaTeX 里 `\tableofcontents` 保持注释） |
| 页码 | 从**摘要页**起、阿拉伯数字、**页脚居中**、连续编号 | ✅ 模板自动处理（承诺书/编号页不计页码） |
| 论文结构 | 第1页承诺书 → 第2页编号页 → 第3页摘要 → 正文 | ✅ `\maketitle` / `cover-display:true` 自动生成 |
| 电子版 | **第一页必须是摘要**，不含承诺书/编号页 | ✅ LaTeX 用 `withoutpreface` 选项；Typst 设 `cover-display:false` |
| 文件 | PDF 或 Word（建议**非图片 PDF**），**≤ 20MB**，论文本身不压缩 | ⚠️ 自查：图多时压图 dpi |
| 支撑材料 | 单个 ZIP/RAR，**≤ 20MB** | ⚠️ 自查 |

**两个提醒：**
1. **承诺书/编号页文字**：模板内置的是近年版本（年份用变量自动更新）。正式赛前**务必从官方当年管理系统下载最新承诺书/编号页比对**——这页"请勿改动内容和格式"。
2. Typst 模板编译时会有 `simkai 字体未找到` 警告，只影响承诺书页楷体显示（电子版会去掉该页），不影响正文；介意可把 `template/fonts/Sim/SimKai.ttf` 的字体族名对上或换楷体。

## 二、摘要填空模板（全文最重要的一页）

> 评委先看摘要定档次。铁律：**每个问题都要有带数字的量化结论**，不要只写"建立了模型"。
> 长度控制在 **3/4 ~ 1 页**，结构如下：

```
针对【背景一句话】，本文【总体思路】，解决了 N 个问题。

针对问题一，【数据如何处理】，建立了【什么模型】，采用【什么方法/工具】求解，
            得到【关键结果：具体数字 + 单位】。

针对问题二，……，得到【数字结果】。

针对问题三，……，得到【数字结果】。

本文进一步对【关键参数】做了灵敏度分析，结果表明模型【稳健性结论】。
本文的创新点/亮点在于【一句话】。

关键词：词1  词2  词3  词4
```

### 摘要范例（以 2023 C 题"蔬菜定价与补货"为例，供仿写）

> 针对商超蔬菜品类的定价与补货决策问题，本文以历史销售数据为基础，综合运用**统计分析、时间序列预测与优化模型**，依次解决了三个问题。
>
> 针对问题一，对 6 个品类、251 个单品的销量数据做清洗与聚合后，采用 **Pearson 相关分析与热力图**刻画品类间关系，发现花叶类与辣椒类销量相关系数高达 **0.82**，并通过分布拟合得出各品类销量近似服从**对数正态分布**。
>
> 针对问题二，先用 **ARIMA 模型**预测各品类未来一周日销量（平均 MAPE 为 **8.3%**），再以"成本加成定价—销量"关系为约束，建立**以周收益最大化为目标的非线性规划模型**，求得最优补货量与加成定价方案，使预测周总收益达到 **¥X 万元**，较基准提升 **12.4%**。
>
> 针对问题三，在单品层面引入"可售单品数 27~33、单品最小陈列量 2.5kg"约束，建立**整数规划模型**并用启发式算法求解，给出 7 月 1 日的具体单品补货与定价表。
>
> 最后对成本加成系数做 ±10% 灵敏度分析，最优收益波动小于 **3%**，表明方案稳健。本文亮点在于将预测与优化**两阶段耦合**，使定价决策可随预测滚动更新。
>
> **关键词**：相关分析  ARIMA  非线性规划  整数规划  定价策略

## 三、各章节写作骨架 + 可复用句式

### 1. 问题重述
- 用**自己的话**复述，不照抄题目。背景 2~3 句 + 逐条列出"问题一/二/三要做什么"。
- 句式："本文需要解决以下问题：(1)……；(2)……；(3)……。"

### 2. 问题分析
- 每问点明**属于哪类**（评价/优化/预测/机理）+ **为什么选这个模型** + 思路链条。
- 句式："问题一要求……，本质是一个【优化/预测/评价】问题，故考虑建立……模型。"
- 建议放一张**总体技术路线流程图**（用 draw.io / PPT 画，导出 png）。

### 3. 模型假设（见下方"假设库"直接挑）
- 每条假设都要**后文用得上**，不要凑数。

### 4. 符号说明
- 三线表，符号 + 含义（+ 单位）。正文首次出现的符号也要就地解释。

### 5. 模型建立与求解（每问闭环）
- **建模**：数据预处理 → 写目标函数/约束/公式（**公式编号**）→ 说明每个符号。
- **求解**：用什么算法/工具（对应 `code/` 模块），求解步骤/流程。
- **结果**：图表呈现 + **量化解读**。图必须有"编号+标题+坐标轴单位"。

### 6. 检验与灵敏度分析（见下方"评价库"）
- 句式："当参数 X 在 ±10% 范围内变化时，最优解/预测值变化不超过 Y%，说明模型具有较好的稳健性。"

### 7. 模型评价、改进与推广
- 优点 2~3 条 + 缺点 1~2 条（诚实）+ 改进方向 + 可推广到的场景。

## 四、模型假设库（按需挑用，改成本题语境）

- 假设题目所给数据真实可靠，不考虑测量/统计误差对结论的根本性影响；
- 假设研究时段内不发生突发外部事件（政策调整、自然灾害、市场剧变等）；
- 假设【关键变量】随时间连续/平稳变化，可用【微分方程/时间序列】刻画；
- 假设各【个体/样本】相互独立，互不影响；
- 假设【某次要因素】影响很小，可忽略不计；
- 假设市场/系统在研究期内处于【均衡/稳定】状态；
- 假设【成本/价格/转化率】等参数在短期内保持不变。

## 五、模型评价句式库

**优点：**
- 模型紧扣题意，充分利用了题目给定的【数据/约束】，结果有实际意义；
- 方法成熟可靠，求解结果**可解释、可复现**；
- 模型结构清晰，对【数据规模/噪声/缺失】有较好的适应性；
- 将【预测与优化 / 多个子模型】有机结合，体现了综合建模能力。

**缺点：**
- 为简化计算做了【某假设】，与实际情况可能存在一定偏差；
- 模型对【某参数】较为敏感，参数估计误差会传导至结果；
- 启发式算法不保证全局最优 / 计算复杂度随规模上升较快。

**改进与推广：**
- 放松【某假设】、引入【更强方法，如机器学习/鲁棒优化】可提升精度；
- 本模型框架可推广至【同类问题：如其他定价、调度、评价场景】。

## 六、写作纪律（拿省一的细节）

1. **写作手 Day1 就动笔**：问题重述、假设、符号、技术路线先写，别等最后一天。
2. **图表规范**：图有编号+标题+轴单位；表用三线表；公式编号；正文引用 `图1/式(2)`。
3. **结果可复现**：正文每个数字都能在附录代码/数据里对上。
4. **摘要最后打磨**：Day3 下午留足时间重写摘要，把每问最硬的数字提到摘要。
5. **先完整再深入**：宁可三问都闭环、写清楚，也不要一问做到顶、其余空着。
