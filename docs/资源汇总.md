## 三、建议的学习路径
1. 先用 `intro-mathmodel`（Python）打通"读题 → 建模 → 求解 → 可视化"全流程。
2. 选定 LaTeX 或 Typst 模板，提前把论文骨架跑通（摘要、问题重述、模型、求解、灵敏度、检验）。
3. 精读 2–3 个**单题完整仓库**（含论文 + 代码），体会获奖论文的结构与表达。
4. 用 `Math_Model` / `MathModel` 当算法字典，按需查"预测/优化/评价/分类"模型。

## 四、本地已整理资料入口

当前仓库已经沉淀了可直接赛前查阅的本地材料：

| 路径 | 用途 |
|------|------|
| `past-problems/external-projects/README.md` | 外部完整工程索引，按主读工程、同题对照、资料库和链接备查分类 |
| `docs/往年优秀工程建模手法分析.md` | 从 A/B/C 往年工程中总结建模翻译方法：变量、目标、约束、算法和检验 |
| `docs/优秀论文排版画图与摘要写作方法.md` | 总结优秀论文的摘要写法、排版结构、图表方案和提交前检查清单 |
| `MathModel-Figure-Toolkit/` | 绘图模板和论文插图生成工具，比赛时优先用于统一图表风格 |
| `refs/external-tools/README.md` | 外部工具参考索引，目前包含队友推荐的 Beacon 多智能体建模流水线 |

建议赛前精读顺序：

1. 先读 `docs/往年优秀工程建模手法分析.md`，建立 B/C 题建模套路。
2. 再读 `docs/优秀论文排版画图与摘要写作方法.md`，明确论文第一页、图表和摘要标准。
3. 最后按选题方向进入 `past-problems/external-projects/README.md` 挑 2-3 个主读工程。
4. 如需设计 AI 协作流程，再参考 `refs/external-tools/Beacon/` 的节点拆分和质量检查机制。
