# 数据字典

## 原始监测数据

| 字段 | 统一名称 | 含义 | 处理规则 |
|---|---|---|---|
| 工作表 `A_1`—`A_10` | `asset` | 设备编号 | 转换为 `A1`—`A10` |
| `time` | `timestamp` | 采样时间 | 转为本地无时区时间，非法值记缺失 |
| `per` | `performance` | 设备性能 | 转为浮点数，不在原始层填补 |

## 原始维护数据

| 字段 | 统一名称 | 含义 | 处理规则 |
|---|---|---|---|
| `编号` | `asset` | 设备编号 | 规范为 `A1`—`A10` |
| `日期` | `maintenance_date` | 维护发生日期 | 归一到日 |
| `维护类型` | `maintenance_type` | 中维护或大维护 | 统一为 `medium` / `major` |

题目提到的小维护没有单独记录，不能从附件中直接估计其因果效果；若后续纳入优化，应作为假设参数并做敏感性分析。

## 日级面板

| 字段 | 含义 |
|---|---|
| `performance_mean/median/std/min/max` | 当日有效监测值的描述统计 |
| `sample_rows` | 当日原始记录数 |
| `valid_rows` | 当日有效性能记录数 |
| `missing_rate` | 当日原始记录中的性能缺失率 |
| `performance_model` | 供建模使用的日性能；只对不超过配置长度的短缺口插值 |
| `was_imputed` | 当日模型值是否由短缺口插值得到 |
| `maintenance_type` | 当日维护类型；无维护为空 |
| `days_since_maintenance` | 距离最近一次有记录维护的天数 |
