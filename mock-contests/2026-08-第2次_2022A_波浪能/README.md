# 2026-08 第 2 次模拟：2022A 波浪能最大输出功率设计

## 本次目标

用一套完整的国赛 A 题检验仓库在 Windows 侧完成机理建模、数值求解、参数优化、结果制表和论文绘图的能力，并为 Mac 侧论文写作提供可直接接手的材料包。

## 零参考规则

- 允许读取：官方题面、官方附件、官方空白结果模板。
- 允许使用：本仓库通用环境、通用数值计算库、通用绘图规范和论文模板。
- 禁止读取：任何 2022A 解题论文、题解、博客、视频、参考代码或已有结果。
- 禁止从 `past-problems/external-projects/`、`recent-examples/`、网络搜索结果中查找本题思路。
- 所有模型推导、代码结构、参数选择、验证方案和结论均在本目录内独立产生。
- 如需查询通用物理或数值方法，只记录查询主题与来源，不查询“2022A 波浪能”相关内容。

## 平台分工

- Windows：题面解析、数据核验、建模、编程、数值实验、优化、绘图、结果表和复现检查。
- Mac：论文正文写作、LaTeX/Typst 排版、摘要润色和最终 PDF 检查。
- 交接目录：`paper/handoff/`，只放稳定结论、公式、表格、最终图片索引和写作说明。

## 目录

- `data/raw/`：官方原始文件，只读使用。
- `data/processed/`：脚本生成的结构化参数。
- `code/q1` 至 `code/q4`：四问独立入口。
- `results/`：数值表、模型参数和验证结果。
- `figures/final/`：Mac 论文只引用这里的图片。
- `notes/`：题意拆解、推导、假设、决策和进度。
- `paper/handoff/`：Windows 到 Mac 的论文材料包。
