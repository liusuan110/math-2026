# 代码入口约定

- `common/q1_dynamics.py`：问题一参数、阻尼函数、动力学方程、能量核验和统一积分器。
- `q1/verify_q1.py`：问题一短时自动验证；当前包含 9 项测试。
- `q1/solve_q1.py`：两种直线阻尼下的完整 40 周期响应、收敛、能量、频域和物理范围验证。
- `q1/plot_q1_validation.py`：问题一诊断图，仅用于数值效果检查。
- `q2/solve_q2.py`：常量阻尼与幂律阻尼优化。
- `q3/solve_q3.py`：垂荡-纵摇响应。
- `q4/solve_q4.py`：直线与旋转阻尼联合优化。
- 根级统一入口将在模型稳定后补充。

所有脚本以本模拟目录为基准解析路径，不依赖当前工作目录。问题一公共模块已通过编译检查和 9/9 自动测试；完整 40 周期计算的全部验收项已通过。
