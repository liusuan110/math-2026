# 代码入口约定

- `common/q1_dynamics.py`：问题一参数、阻尼函数、动力学方程、能量核验和统一积分器。
- `q1/verify_q1.py`：问题一短时自动验证；当前包含 9 项测试。
- `q1/solve_q1.py`：两种直线阻尼下的完整 40 周期响应、收敛、能量、频域和物理范围验证。
- `q1/plot_q1_validation.py`：问题一诊断图，仅用于数值效果检查。
- `common/q2_power.py`：问题二情形 2 参数、常量阻尼频域功率计算器、幂律阻尼长时周期计算器和周期射击计算器。
- `q2/verify_q2_calculators.py`：问题二目标函数计算器自动验证；当前包含 10 项测试，不执行参数寻优。
- `q2/optimize_q2_constant.py`：问题二常量阻尼的全域扫描、有界优化、解析最优条件与时域复核。
- `q2/design_q2_nonlinear_search.py`：用固定哨兵点验证幂律阻尼快速筛选、严格复算和冷启动基准的一致性；不搜索最优参数。
- `q2/scan_q2_nonlinear_coarse.py`：执行幂律阻尼 \(21\times11\) 全参数域粗网格，识别高功率脊线与边界趋势。
- `q2/refine_q2_nonlinear_ridge.py`：沿固定指数追踪高功率脊线，并用三个二维起点审计稳定内部极大点。
- `q2/optimize_q2_nonlinear_boundary.py`：固定 \(a=100000\)，执行 501 点全指数扫描、一维精修和邻域扰动检查。
- `q2/validate_q2_nonlinear_final.py`：最终级指数精修、双向微扰、零初猜射击、冷启动长时积分、周期能量和物理范围复核。
- `q2/plot_q2_paper.py`：生成问题二三张正式论文图，输出 PNG、SVG、PDF。
- `q2/summarize_q2.py`：汇总最终参数、功率、验收状态、正式图路径和 SHA-256。
- `q2/verify_q2_delivery.py`：核验最终汇总、九个正式图文件和 Mac 写作交接内容。
- `q3/solve_q3.py`：垂荡-纵摇响应。
- `q4/solve_q4.py`：直线与旋转阻尼联合优化。
- 根级统一入口将在模型稳定后补充。

所有脚本以本模拟目录为基准解析路径，不依赖当前工作目录。问题一公共模块已通过编译检查和 9/9 自动测试；完整 40 周期计算的全部验收项已通过。问题二目标函数计算器已通过编译检查和 10/10 自动测试，常量阻尼优化已通过 8/8 项结果验收，幂律阻尼搜索设计已通过 6/6 项验收，粗网格扫描已通过 8/8 项验收，内部脊线精修已通过 9/9 项验收，上边界优化已通过 12/12 项验收，幂律最终复核已通过 19/19 项验收。
