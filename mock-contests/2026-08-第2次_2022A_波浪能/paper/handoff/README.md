# Mac 论文写作交接区

问题一、问题二和问题三的 Windows 侧工作均已完成并通过验收。本目录现在包含：

- `模型与公式.md`：坐标、符号、假设、方程、参数与求解方法。
- `结果与结论.md`：题目指定时刻、响应规律和验证结论。
- `问题一正文草稿.md`：可直接改写进论文的中文正文。
- `问题二正文草稿.md`：问题二优化模型、搜索过程、最终结果和检验正文。
- `问题三正文草稿.md`：问题三四自由度模型、响应、PTO 输出和检验正文。
- `图表索引.md`：正式图片、结果表、建议图注和正文引用位置。
- `复现说明.md`：代码入口、运行方式、结果来源和验收文件。
- `写作待办.md`：Mac 侧排版、摘要和终检清单。

使用规则：

1. 论文图片只从 `../../figures/final/` 引用。
2. 正式结果表只从 `../../results/tables/` 引用。
3. 不从 `figures/q1/validation/`、控制台或临时 PDF 渲染目录复制数值。
4. 正文关键数值以 `结果与结论.md` 为准；问题一完整序列以两个 Excel 工作簿为准，问题二和问题三最终汇总分别以 `../../results/models/q2_final_summary.json`、`../../results/models/q3_final_summary.json` 为准。
