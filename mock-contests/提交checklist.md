# 提交 Checklist（每次模拟 + 正式赛都走一遍）

> ⚠️ 以下规则整理自 [备赛指南 §1](../docs/备赛指南.md)，**正式赛以官方当年《报名和参赛须知》为准**。
> 标 ❗ 的是最容易翻车、丢资格的点。

## 一、论文结构（纸质版顺序）

- [ ] 第 1 页：**承诺书**（签名）
- [ ] 第 2 页：**编号专用页**
- [ ] 第 3 页：**摘要专用页**——❗ 页码**从这一页起**用阿拉伯数字编为第 1 页
- [ ] 第 4 页起：正文
- [ ] **正文 ≤ 30 页**（❗ 2026 新规，别用"20 页"旧说法）
- [ ] **不要目录**
- [ ] 附录：页数不限，放完整代码

## 二、摘要（评审第一眼，权重最高）

- [ ] **≤ 1 页**
- [ ] 含标题与**关键词**
- [ ] **无需英文摘要**
- [ ] 每个问题都有**具体量化结论**（带数字），不只是"建立了模型"
- [ ] 讲清 问题 → 方法 → 关键结果(数字) → 结论

## 三、电子版（与纸质版不同！）

- [ ] ❗ 电子版**不含承诺书、不含编号页**——第一页就是摘要页
- [ ] 文件为 **PDF 或 Word**（二选一）
- [ ] ❗ 建议**非图片 PDF**（文字可复制、可检索）
- [ ] ❗ 论文单文件 **≤ 20MB**（图太多就压缩图片 dpi / 转存）

## 四、支撑材料（可选，但建议交）

- [ ] 代码、数据、补充图表打包
- [ ] ❗ 压成**单个 ZIP 或 RAR**（WinRAR），同样 **≤ 20MB**
- [ ] 解压后目录清晰、有 README 说明怎么跑

## 五、提交流程（务必提前演练）

- [ ] 在官方系统 **https://cumcm.cnki.net** 完成
- [ ] ❗ 按时提交 **MD5 码**（推断 9/13 20:00，以官方为准）
- [ ] ❗ 按时上传**最终作品**（推断 9/14 14:00，以官方为准）
- [ ] 预留 **≥ 2 小时**走完整提交，别卡点
- [ ] 提交后**确认系统显示成功**、留截图

## 六、提交前最后扫一遍

- [ ] 论文里所有图都有**编号 + 标题 + 坐标轴单位**
- [ ] 所有表用**三线表**
- [ ] 公式有编号
- [ ] 正文引用的结果数字能和代码/附录对上（可复现）
- [ ] 队号、题号填写正确
- [ ] 文件名符合官方要求
