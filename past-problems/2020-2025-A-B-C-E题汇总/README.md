# 2020-2025 年全国大学生数学建模竞赛 A、B、C、E 题汇总

本目录收录 2020-2025 年高教社杯全国大学生数学建模竞赛 A、B、C、E 题及官方附件，共 6 年、24 道题。题目文件来自全国大学生数学建模竞赛组委会官网，目录统一为 `年份/题号题`，例如 `2024/A题/`。

> 使用说明：题目与附件用于个人学习和校内训练。本文的“推荐建模路线”是备赛建议，不是组委会标准答案，也不代表唯一正确解法。

> 兼容性说明：组委会发布的 2020 年题目原文件是 DOCX。Microsoft Word 可正常读取其文本；部分 LibreOffice/在线预览器可能因中文字体或公式对象兼容性出现空白字形，遇到这种情况可直接参考本页逐题梳理。

> 大文件说明：2024 E 题 `附件2.csv` 约 468 MB，已保留在本地目录中供查看，但在 `.gitignore` 中单独忽略，避免后续推送到 GitHub 时超过单文件大小限制。

## 二、逐年题目梳理

### 2020 年

#### A 题：炉温曲线

- 任务：建立回焊炉内电路板焊接区域中心温度变化模型，预测炉温曲线并优化温区设定和传送带速度。
- 数据：实验炉温曲线、温区长度、间隙、制程界限、结果模板。
- 路线：热传导/一阶惯性模型 -> 参数辨识 -> 制程约束判定 -> 单目标和多目标优化。
- 难点：炉内环境温度分段连续、传送速度影响停留时间、峰值温度和高温面积约束相互牵制。
- 本地入口：[`2020/A题/`](./2020/A题/)

#### B 题：穿越沙漠

- 任务：在负重、资金、天气、补给和矿山收益约束下规划玩家购买、移动、停留和挖矿策略。
- 数据：地图、天气序列、资源消耗参数、收益参数和结果模板。
- 路线：状态空间设计 -> 动态规划/最短路 -> 随机动态规划 -> 多人博弈或仿真。
- 难点：状态维数膨胀、村庄补给时机、不确定天气信息结构、多人相互影响规则。
- 本地入口：[`2020/B题/`](./2020/B题/)

#### C 题：中小微企业的信贷决策

- 任务：量化企业信贷风险，确定贷款对象、额度和利率，并考虑突发事件影响。
- 数据：企业基本信息、进销项发票、违约标签、利率-流失率关系。
- 路线：发票清洗与特征工程 -> 风险评分/分类 -> 收益-风险优化 -> 压力测试。
- 难点：发票级数据聚合、类别不平衡、风险和收益目标统一、突发因素量化边界。
- 本地入口：[`2020/C题/`](./2020/C题/)

#### E 题：校园供水系统智能管理

- 任务：分析校园水表用水规律、建立层级关系模型、识别漏损并提出维修决策。
- 数据：水表层级关系、四个季度多水表读数和用水数据。
- 路线：时间序列清洗 -> 分区用水画像 -> 层级水量平衡 -> 漏损检测/定位 -> 成本收益决策。
- 难点：水表层级误差传播、周期性和异常区分、暗漏定位、维修成本假设要可解释。
- 本地入口：[`2020/E题/`](./2020/E题/)

### 2021 年

#### A 题：“FAST”主动反射面的形状调节

- 任务：确定理想抛物面并给出主动反射面促动器伸缩方案，比较调节后接收比。
- 数据：主索节点、促动器、反射面板连接关系和结果模板。
- 路线：球面/抛物面几何 -> 坐标变换 -> 约束最小二乘 -> 促动器径向位移求解 -> 光线追踪评估。
- 难点：节点间距变化约束、促动器伸缩范围、离散面板近似、接收比计算必须和几何模型一致。
- 本地入口：[`2021/A题/`](./2021/A题/)

#### B 题：乙醇偶合制备 C4 烯烃

- 任务：分析温度、催化剂组合和装料方式对转化率、选择性与收率的影响，求高收率条件并设计新增实验。
- 数据：小样本多因素实验观测。
- 路线：探索性分析 -> 非线性回归/方差分析 -> 响应面或代理模型 -> 约束优化 -> 实验设计。
- 难点：样本不均衡、变量耦合、外推风险、“最优点”需要误差和验证方案。
- 本地入口：[`2021/B题/`](./2021/B题/)

#### C 题：生产企业原材料的订购与运输

- 任务：评价供应商重要性，制定未来 24 周订购和转运方案，并估计最大产能。
- 数据：402 家供应商 240 周订货-供货序列、8 家转运商损耗率。
- 路线：履约率和稳定性特征 -> 综合评价 -> 多期库存模型 -> 混合整数规划/网络流 -> 情景检验。
- 难点：供货不确定性、两周安全库存、每周运力、单一转运商等离散约束。
- 本地入口：[`2021/C题/`](./2021/C题/)

#### E 题：中药材的鉴别

- 任务：利用近红外和中红外光谱鉴别中药材类别与产地。
- 数据：多附件光谱矩阵，含药材编号、类别、产地和波数-吸光度序列。
- 路线：光谱预处理 -> 降维/特征波段选择 -> 分类模型 -> 近中红外融合验证 -> 未知样本判别。
- 难点：高维小样本、产地差异弱、不同药材有效波段不同、分类结果需要置信度或稳定性说明。
- 本地入口：[`2021/E题/`](./2021/E题/)

### 2022 年

#### A 题：波浪能最大输出功率设计

- 任务：建立浮子-振子运动模型，模拟垂荡/纵摇响应并优化阻尼器参数使平均输出功率最大。
- 数据：动画示意、波浪频率下水动力参数、浮子和振子几何物理参数、结果模板。
- 路线：动力学微分方程 -> 数值积分 -> 平均功率计算 -> 单/双阻尼参数优化 -> 灵敏度分析。
- 难点：非线性阻尼、耦合垂荡与纵摇、初始过渡过程处理、功率统计窗口选择。
- 本地入口：[`2022/A题/`](./2022/A题/)

#### B 题：无人机遂行编队飞行中的纯方位无源定位

- 任务：仅利用接收无人机看到的发射无人机夹角进行定位，并设计圆形和锥形编队调整方案。
- 数据：理想编队几何参数和有偏差初始极坐标。
- 路线：平面几何/圆周角关系 -> 非线性方程与最小二乘 -> 可观测性判别 -> 迭代编队控制。
- 难点：多解、编号未知组合匹配、基准机误差传播、收敛性证明。
- 本地入口：[`2022/B题/`](./2022/B题/)

#### C 题：古代玻璃制品的成分分析与鉴别

- 任务：分析玻璃类型、纹饰、颜色与风化关系，预测风化前成分并分类鉴别未知样品。
- 数据：成分比例、类别标签、风化标签、纹饰和颜色等混合变量。
- 路线：有效样本筛选 -> 成分数据变换 -> 统计检验/回归 -> 分类 -> 聚类/亚类划分 -> 扰动敏感性。
- 难点：成分总和约束、小样本、缺失与异常、分类稳定性。
- 本地入口：[`2022/C题/`](./2022/C题/)

#### E 题：小批量物料的生产安排

- 任务：选择重点物料，预测周需求，并在服务水平约束下制定滚动生产计划。
- 数据：2019-2022 年物料需求历史数据。
- 路线：物料筛选 -> 周级聚合与预测 -> 库存/缺货递推 -> 服务水平约束优化 -> 交付提前期推广。
- 难点：需求间歇性、预测误差进入生产计划、库存资金占用与缺货损失权衡、不能使用未来实际需求。
- 本地入口：[`2022/E题/`](./2022/E题/)

### 2023 年

#### A 题：定日镜场的优化设计

- 任务：计算定日镜场年平均光学效率和输出热功率，并优化吸收塔、镜面尺寸、高度和布置。
- 数据：定日镜坐标、太阳位置采样规则、结果模板。
- 路线：太阳几何 -> 余弦/阴影遮挡/截断/大气透射效率 -> 镜场仿真 -> 布局优化。
- 难点：遮挡判定计算量大、非凸布局优化、额定功率约束、不同镜面尺寸时变量规模迅速上升。
- 本地入口：[`2023/A题/`](./2023/A题/)

#### B 题：多波束测线问题

- 任务：推导斜坡海底覆盖宽度和重叠率，设计最短全覆盖测线，并在真实测深网格上控制漏测和过度重叠。
- 数据：规则参数表、海域测深网格和结果模板。
- 路线：几何推导 -> 等效坡度/向量模型 -> 递推布线/约束优化 -> 地形插值与分区 -> 覆盖评价。
- 难点：覆盖宽度左右不对称、边界覆盖、复杂地形分区、多目标权衡。
- 本地入口：[`2023/B题/`](./2023/B题/)

#### C 题：蔬菜类商品的自动定价与补货决策

- 任务：分析蔬菜销量规律，预测未来需求，制定品类级补货定价和单品组合策略。
- 数据：商品信息、三年销售流水、批发价格和损耗率。
- 路线：流水清洗 -> 日级聚合 -> 需求预测 -> 价格弹性估计 -> 报童模型/非线性优化 -> 混合整数规划。
- 难点：价格、季节和供给混杂，相关不等于因果，预测误差需要进入安全量。
- 本地入口：[`2023/C题/`](./2023/C题/)

#### E 题：黄河水沙监测数据分析

- 任务：估算水流量和排沙量，分析突变、季节性和周期性，预测趋势并评价调水调沙效果。
- 数据：近 6 年水位、水流量、含沙量、河断面和监测点数据。
- 路线：水沙通量计算 -> 时间序列分解/突变检验 -> 预测 -> 采样方案优化 -> 河底高程变化评估。
- 难点：不规则监测和插值、汛期突变、采样成本与信息量权衡、反事实“无调水调沙”假设。
- 本地入口：[`2023/E题/`](./2023/E题/)

### 2024 年

#### A 题：“板凳龙”闹元宵

- 任务：描述 223 节板凳龙沿螺线盘入/盘出的运动，判断碰撞边界并优化调头空间和速度。
- 数据：板凳尺寸、孔位、螺线参数、结果模板。
- 路线：阿基米德螺线弧长参数化 -> 链式刚体几何递推 -> 速度传播 -> 碰撞检测 -> 曲线/速度优化。
- 难点：长链约束递推、把手位置和板凳轮廓不同、碰撞判定精度、局部调头路径设计。
- 本地入口：[`2024/A题/`](./2024/A题/)

#### B 题：生产过程中的决策问题

- 任务：设计抽样接收方案，并决定零配件、半成品、成品是否检测以及不合格品是否拆解。
- 数据：次品率、采购/检测/装配/拆解成本、售价和调换损失。
- 路线：单侧假设检验/序贯检验 -> 决策树/期望收益 -> 动态规划 -> 参数不确定性与稳健决策。
- 难点：循环拆解计账、概率条件一致性、抽样估计不能当作无误差真值。
- 本地入口：[`2024/B题/`](./2024/B题/)

#### C 题：农作物的种植策略

- 任务：在土地、季节、轮作、豆类约束和销售上限下制定 2024-2030 年种植计划。
- 数据：地块与大棚、作物种植条件、2023 年种植与经济数据、结果模板。
- 路线：多期混合整数规划 -> 情景生成/蒙特卡洛 -> 稳健优化 -> 相关随机变量模拟。
- 难点：轮作和三年豆类约束、地块分散度、销售量分段收益、七年决策规模。
- 本地入口：[`2024/C题/`](./2024/C题/)

#### E 题：交通流量管控

- 任务：估计交叉口分时段各相位流量，优化信号灯配置，识别巡游车辆并评价五一管控效果。
- 数据：路段方向编号、交叉口距离、4 月 1 日至 5 月 6 日车辆过点记录、管控方案。
- 路线：车辆轨迹重构 -> 分时段流量估计 -> 信号配时优化/仿真 -> 巡游车辆识别 -> 管控前后对比。
- 难点：监控只记录过点方向不直接给转向、车辆可中途出现消失、超大 CSV 处理、节假日行为异质性。
- 本地入口：[`2024/E题/`](./2024/E题/)

### 2025 年

#### A 题：烟幕干扰弹的投放策略

- 任务：设计无人机航向、速度、投放点和起爆点，使烟幕对来袭导弹和真目标形成尽可能长的有效遮蔽。
- 数据：导弹、无人机、目标初始位置和结果模板。
- 路线：三维运动学 -> 视线遮蔽判定 -> 单弹优化 -> 多弹时序规划 -> 多无人机多导弹协同优化。
- 难点：遮蔽是空间几何和时间区间的联合约束，多弹遮蔽可不连续，问题强非凸且变量多。
- 本地入口：[`2025/A题/`](./2025/A题/)

#### B 题：碳化硅外延层厚度的确定

- 任务：由红外干涉光谱反演外延层厚度，分析不同入射角可靠性，并研究多光束干涉影响。
- 数据：碳化硅和硅晶圆片在不同入射角下的波数-反射率光谱。
- 路线：光程差和色散关系 -> 光谱去趋势/去噪 -> 峰谷或频域周期提取 -> 非线性最小二乘 -> 多入射角验证。
- 难点：折射率随波长变化、峰值识别误差、厚度整数级次歧义、多光束判别。
- 本地入口：[`2025/B题/`](./2025/B题/)

#### C 题：NIPT 的时点选择与胎儿的异常判定

- 任务：分析 Y 染色体浓度与孕周、BMI 等因素关系，对男胎孕妇分组确定检测时点，并建立女胎异常判定方法。
- 数据：孕妇基本信息、重复检测、孕周、BMI、测序质量指标、染色体浓度/Z 值和出生后健康结果。
- 路线：数据质控 -> 混合效应/广义加性模型 -> 首次达标时间/生存分析 -> 分段分组优化 -> 分类与概率校准。
- 难点：同一孕妇多次检测非独立、检测误差、分组边界稳定性、医疗判定漏判代价。
- 本地入口：[`2025/C题/`](./2025/C题/)

#### E 题：AI 辅助智能体测

- 任务：基于立定跳远视频和人体关键点数据识别起跳/落地，分析成绩影响因素并给出训练建议。
- 数据：跳远视频、33 个关键点逐帧坐标、成绩、体质报告、关键点示意图。
- 路线：姿态序列清洗 -> 起跳/落地事件检测 -> 运动学特征提取 -> 成绩回归/因子分析 -> 个体化建议。
- 难点：视频和关键点数据同步、遮挡和噪声、短期训练前后可比性、建议要落到可解释动作指标。
- 本地入口：[`2025/E题/`](./2025/E题/)

## 三、六年变化趋势

### A 题趋势

1. 机理含量最高：热过程、望远镜反射面、波浪能、太阳能镜场、板凳龙运动、烟幕遮蔽都要求先写清物理或几何机制。
2. 优化变量越来越多：从温区和速度，到镜场布局、多无人机多弹协同，通常需要“可计算的简化模型 + 验证”。
3. 适合准备的通用能力：微分方程、三维几何、数值积分、非线性优化、碰撞/遮挡判定、仿真可视化。

### B 题趋势

1. 题型跨度大：资源决策、化学实验、无人机定位、海洋测绘、质量控制、半导体光学连续切换。
2. “模型-算法-可靠性”链条明显：不仅要给数值，还要说明可辨识性、误差、多解、灵敏度或参数不确定性。
3. 适合准备的通用能力：非线性方程、最小二乘、动态规划、混合整数规划、信号处理、蒙特卡洛和误差传播。

### C 题趋势

1. 主线稳定：数据清洗与特征工程 -> 统计分析/预测 -> 优化决策 -> 稳健性或敏感性分析。
2. 预测与优化常被串联：预测结果必须转成贷款、补货、运输、种植或检测时点决策。
3. 适合准备的通用能力：Pandas 数据清洗、统计检验、回归/分类、时间序列、聚类、混合整数规划和可视化。

### E 题趋势

1. 更偏应用数据和行业场景：供水、光谱鉴别、生产安排、水文、交通、体测，数据结构差异很大。
2. “业务解释”比炫技更重要：E 题常要求给管理建议、识别异常、制定方案或评价效果，结果要能被非算法读者理解。
3. 适合准备的通用能力：大表清洗、时序分析、分类预测、异常检测、分组评价、可解释指标和成本收益分析。

## 四、针对 2026 备赛的学习顺序

- 主攻 A 题：2020 A -> 2022 A -> 2023 A -> 2024 A -> 2025 A。先练机理建模和仿真，再练高维优化。
- 主攻 B 题：2024 B -> 2020 B -> 2022 B -> 2023 B -> 2021 B -> 2025 B。覆盖决策、几何、实验和反演。
- 主攻 C 题：2022 C -> 2020 C -> 2023 C -> 2021 C -> 2024 C -> 2025 C。按“分类-预测优化-多期风险”递进。
- 兼顾 E 题：2021 E -> 2022 E -> 2023 E -> 2024 E -> 2025 E。重点练数据清洗、可解释分析和方案评价。

每题至少完成：题目重述、数据字典、核心公式或约束、基准模型、主程序、误差/敏感性分析、一页结论表。
