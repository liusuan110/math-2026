# 2020—2025 年全国大学生数学建模竞赛 B、C 题汇总

本目录收录 2020—2025 年高教社杯全国大学生数学建模竞赛的 B、C 题及官方附件，共 6 年、12 道题。题目文件来自全国大学生数学建模竞赛组委会官网，目录结构统一为 `年份/B题` 和 `年份/C题`。

> 使用说明：题目与附件用于个人学习和校内训练。本文的“推荐建模路线”是备赛建议，不是组委会标准答案，也不代表唯一正确解法。

> 兼容性说明：组委会发布的 2020 年 B、C 题原文件是 DOCX。Microsoft Word 可正常读取其文本；部分 LibreOffice/在线预览器可能因原文所用中文字体和公式对象缺失而出现空白字形，遇到这种情况可直接参考本页逐题梳理。

## 二、逐年题目梳理

### 2020 年

#### B 题：穿越沙漠

- 题目任务：在负重、资金、天气、截止日期、村庄补给和矿山收益等约束下，规划玩家的购买、移动、停留和挖矿策略。
- 问题递进：已知全部天气的单人最优策略；只知道当天天气的动态策略；多人情形下的预先决策与逐日博弈。
- 数据形态：地图、天气序列、资源消耗参数、收益参数和结果模板。
- 推荐建模路线：状态空间设计 → 动态规划或最短路 → 随机动态规划/马尔可夫决策 → 多人博弈或仿真。
- 关键难点：状态维数膨胀、村庄补给时机、不确定天气下的信息结构，以及多人相互影响规则。
- 本地入口：[`2020/B题/`](./2020/B题/)

#### C 题：中小微企业的信贷决策

- 题目任务：利用企业进销项发票、信誉评级和客户流失率数据量化信贷风险，确定贷款对象、额度和利率，并考虑突发事件影响。
- 问题递进：有历史信贷记录企业的风险与策略；无历史信贷记录企业的迁移预测；突发事件下的策略调整。
- 数据形态：企业基本信息、进销项发票明细、违约标签和利率—流失率关系。
- 推荐建模路线：发票清洗与企业特征工程 → 风险评分/分类模型 → 违约概率与收益联合建模 → 带总额度约束的组合优化 → 压力测试。
- 关键难点：发票级数据聚合、类别不平衡、风险与收益的统一目标、突发因素不能被无依据地量化。
- 本地入口：[`2020/C题/`](./2020/C题/)

### 2021 年

#### B 题：乙醇偶合制备 C4 烯烃

- 题目任务：分析温度、催化剂组合和装料方式对乙醇转化率、C4 烯烃选择性与收率的影响，求高收率工艺条件，并设计 5 次新增实验。
- 问题递进：单因素关系与时间稳定性；多因素影响；全温区和低于 350℃的参数优化；序贯实验设计。
- 数据形态：小样本、多因素、不同温度下的实验观测。
- 推荐建模路线：探索性分析 → 非线性回归/方差分析 → 响应面或代理模型 → 约束优化 → D-最优、响应面或贝叶斯实验设计。
- 关键难点：样本不均衡、变量耦合、外推风险，以及“最优点”必须附带预测误差和验证实验。
- 本地入口：[`2021/B题/`](./2021/B题/)

#### C 题：生产企业原材料的订购与运输

- 题目任务：评价 402 家供应商的重要性，制定未来 24 周的订购和转运方案，并估计现有供应链支持的最大产能。
- 问题递进：供应商评价；最低供应商数量与经济订购/低损耗运输；偏向 A 类、减少 C 类的新方案；最大产能规划。
- 数据形态：402 家供应商 240 周订货—供货序列、8 家转运商 240 周损耗率。
- 推荐建模路线：履约率、稳定性和供货能力特征 → 综合评价/稳健排序 → 多期库存模型 → 混合整数规划或网络流 → 情景检验。
- 关键难点：供应商供货不确定性、两周安全库存、每周运力和尽量单一转运商等离散约束。
- 本地入口：[`2021/C题/`](./2021/C题/)

### 2022 年

#### B 题：无人机遂行编队飞行中的纯方位无源定位

- 题目任务：仅利用接收无人机看到的发射无人机夹角进行定位，研究未知发射机编号时的可辨识性，并设计圆形和锥形编队的位置调整方案。
- 问题递进：已知发射机位置与编号的定位；部分编号未知时最少发射机数量；圆形编队迭代调整；推广到锥形编队。
- 数据形态：理想编队几何参数与一组有偏差的无人机初始极坐标。
- 推荐建模路线：平面几何/圆周角关系 → 非线性方程与最小二乘定位 → 可观测性和多解判别 → 分批基准机选择与迭代编队控制。
- 关键难点：镜像解或多解、编号未知造成的组合匹配、基准无人机误差传播和收敛性证明。
- 本地入口：[`2022/B题/`](./2022/B题/)

#### C 题：古代玻璃制品的成分分析与鉴别

- 题目任务：分析玻璃类型、纹饰、颜色与风化的关系，预测风化前成分，划分高钾/铅钡玻璃及亚类，并鉴别未知样品。
- 问题递进：风化统计规律和成分恢复；类别与亚类划分；未知样品分类；不同类别成分关联差异。
- 数据形态：小样本、成分比例、类别标签、风化标签、纹饰与颜色等混合变量。
- 推荐建模路线：有效样本筛选 → 成分数据变换/标准化 → 列联分析与回归 → 分类模型 → 聚类或层次划分 → 扰动敏感性分析。
- 关键难点：各成分具有总和约束，不能完全按普通独立变量处理；样本量小，必须使用交叉验证或留一验证。
- 本地入口：[`2022/C题/`](./2022/C题/)

### 2023 年

#### B 题：多波束测线问题

- 题目任务：推导斜坡海底的覆盖宽度和重叠率，考虑测线方向影响，设计最短全覆盖测线，并在真实测深网格上综合控制漏测和过度重叠。
- 问题递进：二维坡面模型；任意测线方向的三维模型；规则斜坡上的最短布线；复杂海底上的覆盖优化。
- 数据形态：规则参数表、海域测深网格和结果模板。
- 推荐建模路线：几何推导 → 等效坡度/向量模型 → 递推布线或约束优化 → 地形插值与分区 → 覆盖面积和重叠率计算。
- 关键难点：覆盖宽度左右不对称、边界覆盖、真实地形分区，以及总长度、漏测和过度重叠之间的多目标权衡。
- 本地入口：[`2023/B题/`](./2023/B题/)

#### C 题：蔬菜类商品的自动定价与补货决策

- 题目任务：分析蔬菜销量分布和关联，预测未来需求，制定品类级补货与定价策略，并进一步优化单品组合。
- 问题递进：品类/单品销售规律；未来一周品类级补货定价；限定 27—33 个单品时的单日决策；提出新增数据需求。
- 数据形态：商品信息、三年销售流水、批发价格和近期损耗率。
- 推荐建模路线：流水清洗与日级聚合 → 周期性/相关性分析 → 需求预测 → 价格弹性估计 → 报童模型或非线性优化 → 单品选择混合整数规划。
- 关键难点：销量同时受价格、季节和供给影响，简单相关不等于因果；预测误差需要进入补货安全量或情景优化。
- 本地入口：[`2023/C题/`](./2023/C题/)

### 2024 年

#### B 题：生产过程中的决策问题

- 题目任务：设计少样本抽样接收方案，并决定零配件、半成品和成品是否检测，以及不合格品是否拆解。
- 问题递进：单批次抽样检验；两零配件生产决策；多工序多零配件推广；次品率估计存在误差时重新决策。
- 数据形态：给定次品率、采购/检测/装配/拆解成本、售价和调换损失。
- 推荐建模路线：单侧假设检验或序贯检验 → 决策树/期望收益 → 动态规划或马尔可夫奖励模型 → 多工序状态递推 → 参数不确定性与稳健决策。
- 关键难点：循环拆解与复用必须正确计账，概率条件要保持一致，抽样估计不应被当成无误差真值。
- 本地入口：[`2024/B题/`](./2024/B题/)

#### C 题：农作物的种植策略

- 题目任务：在土地类型、季节、轮作、豆类约束和销售上限下制定 2024—2030 年种植计划，并考虑价格、成本、产量及作物关系的不确定性。
- 问题递进：稳定参数下两种滞销处理；随机参数和风险；替代性、互补性及经济变量相关性。
- 数据形态：地块与大棚信息、作物种植条件、2023 年种植与经济数据、结果模板。
- 推荐建模路线：多期混合整数规划 → 情景生成/蒙特卡洛 → 两阶段或稳健优化 → 相关随机变量模拟 → 与确定性基线比较。
- 关键难点：轮作和三年豆类约束、地块分散度、最小种植面积、销售量分段收益以及七年决策规模。
- 本地入口：[`2024/C题/`](./2024/C题/)

### 2025 年

#### B 题：碳化硅外延层厚度的确定

- 题目任务：由红外干涉光谱反演外延层厚度，分析不同入射角结果的可靠性，并研究多光束干涉的条件、影响和修正方法。
- 问题递进：双光束干涉机理；光谱算法与可靠性；多光束干涉判别、建模及消除影响。
- 数据形态：碳化硅和硅晶圆片在 10°、15°入射角下的波数—反射率光谱。
- 推荐建模路线：光程差和色散关系 → 光谱去趋势/去噪 → 峰谷或频域周期提取 → 非线性最小二乘反演 → 多入射角交叉验证 → 多光束干涉模型。
- 关键难点：折射率随波长变化、峰值识别误差、厚度整数级次歧义，以及多光束干涉不能只靠视觉判断。
- 本地入口：[`2025/B题/`](./2025/B题/)

#### C 题：NIPT 的时点选择与胎儿的异常判定

- 题目任务：分析 Y 染色体浓度与孕周、BMI 等因素的关系，对男胎孕妇分组并确定检测时点，同时建立女胎异常判定方法。
- 问题递进：相关关系与显著性；基于 BMI 的分组和最佳时点；加入身高、体重、年龄和检测误差；女胎染色体异常分类。
- 数据形态：孕妇基本信息、重复采血/重复检测、孕周、BMI、测序质量指标、染色体浓度/Z 值和出生后健康结果。
- 推荐建模路线：数据质控与重复测量整理 → 混合效应/广义加性模型 → 首次达标时间或生存分析 → 分段分组优化 → 分类模型与概率校准。
- 关键难点：同一孕妇多次检测并非独立样本、测序失败机制、分组边界稳定性、类别不平衡和医疗判定的漏判代价。
- 本地入口：[`2025/C题/`](./2025/C题/)

## 三、六年变化趋势

### B 题趋势

1. 题型跨度大：资源决策、化学实验、无人机几何、海洋测绘、质量控制、半导体光学连续切换。
2. 机理建模越来越重要：近年的 B 题通常不能只套通用算法，需要先推导物理、几何或生产过程关系。
3. “模型—算法—可靠性”链条更明显：不仅要给数值结果，还要求说明可辨识性、误差、多解、灵敏度或参数不确定性。
4. 适合准备的通用能力：非线性方程、最小二乘、动态规划、混合整数规划、信号处理、蒙特卡洛和误差传播。

### C 题趋势

1. 主线较稳定：数据清洗与特征工程 → 统计分析/预测 → 优化决策 → 稳健性或敏感性分析。
2. 数据规模和结构越来越复杂：从企业与发票、供应链序列，发展到交易流水、多期种植和重复医学检测。
3. 预测与优化常被串联：只把预测指标做准并不足够，还需要把预测结果转换成贷款、补货、运输、种植或检测时点决策。
4. 验证要求提高：需要防止数据泄漏，使用时间切分、交叉验证、留一验证、情景检验和概率校准。
5. 适合准备的通用能力：Pandas 数据清洗、统计检验、回归/分类、时间序列、聚类、混合整数规划、随机模拟和可视化。

## 四、针对 2026 备赛的学习顺序

### 如果主攻 B 题

- 决策与优化：2024 B → 2020 B。
- 几何与路径：2022 B → 2023 B。
- 实验与反演：2021 B → 2025 B。
- 每题至少完成：公式独立推导、基准算例、误差或敏感性分析、可复现主程序。

### 如果主攻 C 题

- 分类入门：2022 C → 2020 C。
- 预测加优化：2023 C → 2021 C。
- 多期与不确定性：2024 C。
- 纵向数据与风险决策：2025 C。
- 每题至少完成：数据字典、清洗报告、训练/验证划分、基线模型、优化约束检查和一页结论表。
