# 历年真题与获奖实例

本目录收集 CUMCM 历年题目、附件数据与获奖解答，供备赛研读。

## 已收录

### `2020-2025-A-B-C-E题汇总/`

2020—2025 年官方 A、B、C、E 题与附件，共 6 年、24 道题，并附题型、任务链、推荐建模路线、难点和六年趋势总结。

- 阅读入口：[`2020-2025-A-B-C-E题汇总/README.md`](./2020-2025-A-B-C-E题汇总/README.md)
- 来源：[全国大学生数学建模竞赛组委会历年赛题](https://www.mcm.edu.cn/html_cn/block/8579f5fce999cdc896f78bca5d4f8237.html)
- 注：2024 E 题的 `附件2.csv` 约 468 MB，已拉到本地但不纳入 Git 跟踪，避免后续推送到 GitHub 时超过单文件大小限制。

### `solutions-2013-2019/`
2013–2019 年的赛题说明、附件数据与作者获奖解答（论文 + 代码）。
来源：[Amoiensis/Mathmatic_Modeling_CUMCM](https://github.com/Amoiensis/Mathmatic_Modeling_CUMCM)（省一等奖团队）。
> 注：为各年作者实际参赛的题目（多为单题），含 `赛题说明.md` + `data/` + `code/` + `论文.pdf`。
