# 烟幕干扰弹投放策略 · 3D 可视化仿真

基于 **2025 年全国大学生数学建模竞赛 A 题**（烟幕干扰弹的投放策略）搭建的交互式 3D 可视化项目。
物理模型与参考代码完全一致。

## 快速开始

**方式一（推荐）**：直接双击打开 `index.html`，无需联网、无需安装任何依赖
（Three.js 等已内置在 `vendor/` 目录）。

**方式二**：任意本地静态服务器，例如：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 功能一览

### 🎬 场景与参数（左侧面板）
- **场景预设**：一键加载题目 问题1 ~ 问题5 的初始配置（导弹、无人机、干扰弹参数）
- **来袭导弹**：M1/M2/M3 启停、导弹速度、遮蔽判定模式切换
  - `严格遮蔽判定（Q1~Q3 采样法）`：导弹→圆柱上 35 个采样点的视线全部被烟幕截断才算遮蔽
  - 关闭后使用 Q4/Q5 的"圆柱最近点"近似判定
- **物理参数（高级）**：烟幕半径、有效遮蔽时长、云团下沉速度、重力加速度
- **无人机 & 干扰弹**：任意启停 5 架无人机（FY1~FY5），调整每架：
  - 航向角 θ（0~360°，带罗盘图示）
  - 飞行速度（70~140 m/s）
  - 干扰弹数量（每架至多 3 枚）、每枚的投放时刻 t 与起爆延时（投放间隔 ≥1s 约束）

### ⚡ 自动优化
点击顶部"自动优化"，程序按 **蒙特卡洛粗搜 → 局部细化 → 时序贪心**（与参考代码思路一致）
自动搜索使"有效遮蔽并集时长"最大的投放参数，结果直接回填到面板。

### 🕹 时间轴（底部）
- 播放 / 暂停（可随时暂停、拖动任意时间点）
- 0.25× ~ 4× 播放速度
- 相机视角切换：
  - 🔭 自由视角（鼠标拖拽旋转、滚轮缩放）
  - 🛰 俯视
  - 🚁 **无人机视角**（旋转中心锁定所选无人机并随其飞行平移，可自由转动/缩放；点击循环切换 FY1~FY5）
  - 🎯 **导弹视角**（旋转中心锁定当前导弹并随其飞行平移，鼠标自由转动/缩放观察，视线变红表示被遮蔽；点击循环切换 M1~M3）
  - ☁ **烟幕视角**（旋转中心锁定所选烟幕云团中心，云团下沉时同步跟随，可自由转动/缩放；点击循环切换多团云）
- 📐 适配视角：一键框选整个战场

### 📊 遮蔽看板（右侧，可隐藏）
- 每枚导弹一张时间轨道：**被遮蔽的时间区域**用横条显示
- 横条颜色 = 对应无人机，悬停/文字标注显示**具体被哪架无人机的哪枚烟幕弹干扰**
- 播放时红色竖线（playhead）实时指示当前时刻
- 导弹状态徽章：`可见` / `遮蔽中`（闪烁）

## 物理模型（与参考代码一致）

| 项目 | 值 |
| --- | --- |
| 导弹速度 | 300 m/s，匀速直线飞向假目标（原点） |
| 无人机速度 | 70 ~ 140 m/s，等高度匀速直线飞行 |
| 干扰弹 | 无人机飞行 t₁ 后投放，保持水平速度并受重力，延时 t₂ 后起爆 |
| 烟幕云团 | 起爆瞬时形成球体，半径 10 m，以 3 m/s 匀速下沉，有效 20 s（真实比例完整球体） |
| 真目标 | 圆柱：中心 (0,200,0)、半径 7 m、高 10 m（远距离可见半透明定位柱 + 采样点标记） |
| 假目标 | 原点 (0,0,0)，导弹瞄准点 |
| 遮蔽判定 | 导弹→目标圆柱采样点的视线被烟幕球截断（严格/近似两种模式） |
| 视线可视化 | 导弹→目标上/下表面采样点的连线束（绿色=可见，红色=被遮蔽） |

> 说明：导弹锥体、目标定位柱为战场尺度下的**视觉放大**（便于在 20km 级战场中观察），
> 不参与物理计算；烟幕云团保持**真实比例**（半径即物理半径，不缩放）。
>
> 坐标约定：题目坐标系 `(x, y, z)` 中 **z 为高度**（如真目标 `(0,200,0)`、导弹 `(20000,0,2000)`）。
> 渲染时经保向旋转映射到 Three.js 世界坐标 `(x, z, -y)`（世界 Y 轴即高度），不会产生镜像。
