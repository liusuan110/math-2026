# 北太天元 2025 数模竞赛资料

资料来源：

- 微信公众号文章：`https://mp.weixin.qq.com/s/GSCHJgYa4Uuhp6xSLdg13Q`
- 北太天元社区：`https://www.baltamatica.com/community.html`
- 北太天元支持资料页：`https://www.baltamatica.com/support.html`

老师分享的公众号文章主要介绍“北太天元 2025 大赛版”及其面向数学建模竞赛的工具箱升级，包括符号计算、统计学习、优化、深度学习、绘图导出和文件 IO 等能力。文章底部的“阅读原文”指向北太天元社区。

本目录保存的是官网公开的数模培训资料和代码示例，适合备赛时学习和查阅。软件安装包体积较大，且需要结合官网账号、许可证申请和本机安装流程，因此没有下载进仓库。

## 使用建议

1. 赛前优先阅读 `01_全国大学生数学建模竞赛全流程指南.pdf` 和 `09_数学建模竞赛论文写作要点剖析.pdf`。
2. 如果正式赛题涉及 B/C 题常见的数据分析、优化或预测，可查阅 `07_北太天元数据分析和可视化.pdf` 与 `08_算法设计与北太天元实践.pdf`。
3. 如果题目偏 A/B 的机理建模、微分方程或工程仿真，可查看 `10_北太天元微分方程建模代码示例.zip`。
4. 北太天元大赛版安装和 License 申请应以官网当前页面为准，不建议把安装包纳入 Git 仓库。
