# CUMCM2026-Complete-LaTeX

这是一个面向全国大学生数学建模竞赛的完整 LaTeX 论文模板，参考了仓库内原有 `CUMCMThesis` 模板，以及 `2025-B-sic-thickness-national-first` 工程中的论文结构和 AI 工具说明写法。

## 文件说明

- `main.tex`：主论文模板，包含摘要、问题重述、问题分析、模型假设、符号说明、数据预处理、三问建模、检验、评价、结论、参考文献和附录代码。
- `AI工具使用详情说明.tex`：独立的 AI 使用说明模板，可单独编译成 PDF。
- `cumcmthesis.cls`：随模板复制的一份国赛论文类文件，保证本目录可以独立编译。
- `figures/`：放正文图片。
- `code/`：放附录代码，例如 `q1.py`、`q2.py`、`q3.py`、`sensitivity.py`。

## 编译方式

```powershell
latexmk -xelatex main.tex
latexmk -xelatex AI工具使用详情说明.tex
```

## 赛时建议

1. 先改 `main.tex` 顶部的题号、队号、学校和队员信息。
2. 开赛前 12 小时只维护正文结构，不要急着美化语言。
3. 每一问都尽量形成闭环：问题分析、模型建立、算法求解、结果图表、结论解释、稳定性检验。
4. 摘要最后重写，必须带关键数字和明确结论。
5. 正文图片统一放 `figures/`，代码统一放 `code/`，避免赛后提交时找不到文件。
6. 参考 2025B 优秀工程的写法：每个复杂模型都应补齐“决策变量、参数表、目标函数、算法流程、误差检验、稳定性分析”。
